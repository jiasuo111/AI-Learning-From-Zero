## 一、基础语法

### 1.1 数据输出：`print()`

**功能**：将指定内容输出到控制台

**语法**：

python

```
print(要输出的内容, ...)
```



**注意**：

- 字符串需要加**引号**（单引号或双引号）
- 数字、布尔值等可以直接写
- 可以输出多个内容，用逗号分隔

python

```
# 示例
print(10)              # 输出整数
print(3.14)            # 输出浮点数
print("你好世界")       # 输出字符串
print(True)            # 输出布尔值
print(10, 20, "hello") # 输出多个内容
```



------

### 1.2 字面量与注释

#### 字面量

> **概念**：在程序中被固定写死的值，也就是直接在代码中写出来的值。

**字面量基本类型**：

| 类型            | 示例                 |
| :-------------- | :------------------- |
| 整数（int）     | `10`、`-5`、`0`      |
| 浮点数（float） | `3.14`、`-0.5`       |
| 字符串（str）   | `"你好"`、`'Python'` |
| 布尔（bool）    | `True`、`False`      |

#### 注释

> **概念**：对代码进行解释说明的文字，**不参与运行**。

| 注释类型 | 语法               | 说明             |
| :------- | :----------------- | :--------------- |
| 单行注释 | `# 注释内容`       | 只能写一行       |
| 多行注释 | `""" 注释内容 """` | 三引号，可写多行 |

**常用快捷键（PyCharm）**：

| 功能           | 快捷键           |
| :------------- | :--------------- |
| 单行注释       | `Ctrl + /`       |
| 复制光标所在行 | `Ctrl + D`       |
| 格式化代码     | `Ctrl + Alt + L` |

python

```
# 这是单行注释

"""
这是多行注释
可以写多行内容
"""
```

### 1.3 变量

> **概念**：在程序中用于**临时存储数据**的抽象概念。

**语法**：

python

```
变量名 = 变量值
```



> 把 `=` 右边的值**赋值**给左边的变量。

**起名建议**：**见名知意**（用有意义的英文单词）

python

```
# 示例：钱包余额变化
money = 0          # 初始余额
print(money)       # 输出 0

money = money + 100  # 发工资，余额 +100
print(money)       # 输出 100

money = money - 10   # 花钱，余额 -10
print(money)       # 输出 90
```



**变量的好处**：不需要手动修改每一处值，只需改变变量的值即可。

### 1.4 查看数据类型：`type()`

**功能**：查看指定内容的数据类型

**语法**：

python

```
type(内容)
```



python

```
# 查看字面量的类型
print(type(10))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("你好"))   # <class 'str'>
print(type(True))    # <class 'bool'>

# 查看变量的类型
age = 18
print(type(age))     # <class 'int'>
```

### 1.5 数据类型转换

| 函数       | 作用         | 示例                 |
| :--------- | :----------- | :------------------- |
| `int(x)`   | 转换为整数   | `int(3.14)` → `3`    |
| `float(x)` | 转换为浮点数 | `float(10)` → `10.0` |
| `str(x)`   | 转换为字符串 | `str(10)` → `"10"`   |

python

```
# int() 转换
print(int(3.84))     # 3（直接去掉小数部分）
print(int('100'))    # 100
# print(int('3.84')) # 报错！字符串必须是整数形式

# float() 转换
print(float(10))     # 10.0
print(float("3.84")) # 3.84
print(float("100"))  # 100.0

# str() 转换（任意类型都能转）
print(str(10))       # "10"
print(str(3.14))     # "3.14"
print(str(True))     # "True"
```

### 1.6 标识符（命名规则与规范）

> **标识符**：程序中起的各种名字（如变量名、函数名等）。

#### 命名规则（必须遵守）

| 规则         | 说明                                   | 正确示例                 | 错误示例                              |
| :----------- | :------------------------------------- | :----------------------- | :------------------------------------ |
| 内容限定     | 字母、数字、下划线、汉字（不推荐汉字） | `name`、`age1`、`_value` | `1a`（数字开头）、`name!`（特殊符号） |
| 区分大小写   | `a` 和 `A` 是不同的变量                | `a = 10`、`A = 20`       | -                                     |
| 不能是关键字 | 不能使用 Python 保留字                 | `name`、`age`            | `True`、`if`、`for`                   |

**查看 Python 关键字**：

python

```
import keyword
print(keyword.kwlist)
```



#### 命名规范（建议遵守）

| 规范                 | 说明                           | 示例                           |
| :------------------- | :----------------------------- | :----------------------------- |
| 见名知意             | 用有意义的英文单词             | `name`、`age`、`price`         |
| 下划线命名法（蛇形） | 单词之间用下划线               | `person_name`、`product_price` |
| 大驼峰命名法         | 每个单词首字母大写             | `PersonName`、`ProductPrice`   |
| 小驼峰命名法         | 首字母小写，后续单词首字母大写 | `personName`、`productPrice`   |

python

```
# 下划线命名法（Python 推荐）
person_name = "张三"
product_name = "小米15"

# 大驼峰命名法（类名常用）
PersonName = "张三"
ProductName = "小米15"

# 小驼峰命名法（Java/JS 常用）
personName = "张三"
productName = "小米15"
```

### 1.7 运算符

#### 算术运算符

| 运算符 | 含义                 | 示例     | 结果  |
| :----- | :------------------- | :------- | :---- |
| `+`    | 加法                 | `1 + 1`  | `2`   |
| `-`    | 减法                 | `2 - 1`  | `1`   |
| `*`    | 乘法                 | `2 * 3`  | `6`   |
| `/`    | 除法（结果为浮点数） | `9 / 3`  | `3.0` |
| `//`   | 整除（取整）         | `9 // 2` | `4`   |
| `%`    | 取模（取余数）       | `9 % 2`  | `1`   |
| `**`   | 幂运算               | `2 ** 3` | `8`   |

python

```
print(1 + 1)   # 2
print(2 - 1)   # 1
print(2 * 3)   # 6
print(9 / 3)   # 3.0
print(9 // 2)  # 4
print(9 % 2)   # 1
print(2 ** 3)  # 8
```



#### 赋值运算符

| 运算符 | 含义       | 示例      | 等价于       |
| :----- | :--------- | :-------- | :----------- |
| `=`    | 直接赋值   | `a = 10`  | -            |
| `+=`   | 加后赋值   | `a += 3`  | `a = a + 3`  |
| `-=`   | 减后赋值   | `a -= 3`  | `a = a - 3`  |
| `*=`   | 乘后赋值   | `a *= 3`  | `a = a * 3`  |
| `/=`   | 除后赋值   | `a /= 3`  | `a = a / 3`  |
| `//=`  | 整除后赋值 | `a //= 3` | `a = a // 3` |
| `%=`   | 取模后赋值 | `a %= 3`  | `a = a % 3`  |
| `**=`  | 幂后赋值   | `a **= 3` | `a = a ** 3` |

python

```
a = 10
a += 3   # a = 13
a -= 3   # a = 10
a *= 3   # a = 30
a /= 3   # a = 10.0
a //= 3  # a = 3.0
a %= 3   # a = 0.0
a **= 3  # a = 0.0
```

### 1.8 字符串格式化（重点）

#### 字符串定义方式

python

```
# 四种定义方式
print('黑马程序员')
print("黑马程序员")
print('''黑马程序员''')
print("""黑马程序员""")   # 三引号支持换行
```



#### 字符串拼接（不推荐）

python

```
name = "张三"
age = 18
print("姓名:" + name + ",年龄:" + str(age))
```



> ⚠️ 缺点：只能拼接字符串，其他类型需要手动转换。

#### 占位符方式（`%`）

| 占位符 | 说明                                 |
| :----- | :----------------------------------- |
| `%s`   | 字符串占位（任意类型都能转成字符串） |
| `%d`   | 整数占位                             |
| `%f`   | 浮点数占位                           |

python

```
name = "斌子"
age = 18
height = 188.88

# %s 通用占位
s1 = "姓名:%s,年龄:%s,身高:%s" % (name, age, height)
print(s1)

# 指定类型占位
s2 = "姓名:%s,年龄:%d,身高:%.2f" % (name, age, height)
print(s2)  # 姓名:斌子,年龄:18,身高:188.88
```



#### format 方式（Python 3.6+ 推荐）

python

```
# f-string 格式化（最推荐）
s = f"姓名:{name},年龄:{age},身高:{height:.2f}"
print(s)
```



**格式化对比**：

python

```
name = '斌子'
age = 18
height = 188.88

# 方式1：print 多参数
print(name, age, height, sep='---')

# 方式2：+ 拼接
print("姓名:" + name + ",年龄:" + str(age) + ",身高:" + str(height))

# 方式3：% 占位符
print("姓名:%s,年龄:%d,身高:%.2f" % (name, age, height))

# 方式4：f-string（推荐）
print(f"姓名:{name},年龄:{age},身高:{height:.2f}")
```

### 1.9 输入函数：`input()`

**功能**：获取键盘录入的数据

**语法**：

python

```
变量 = input(提示语)
```



**执行步骤**：

1. 将提示语打印到控制台
2. 等待用户输入
3. 将用户输入的内容赋值给左边的变量

> ⚠️ **注意**：`input()` 获取的数据**默认都是字符串类型**！

python

```
# 示例：简易登录程序
name = input('请您输入用户名：')
password = input('请您输入密码：')

print(f'您刚才输入的用户名是：{name}，密码是：{password}')
```
