# Python 控制流程（条件判断）

> 程序不是总是顺序执行的，很多时候我们需要根据不同的情况执行不同的代码。这就是「条件判断」的作用。

------

## 一、`if` 语句

### 基本格式

python

```
if 条件判断:
    条件满足时，执行的代码
```



> ⚠️ **注意**：Python 使用**缩进**来表示层级关系，一个缩进 = 4 个空格（或 1 个 Tab 键）

### 示例：判断是否成年

python

```
# 需求：如果年龄大于等于18，就可以进入网吧

# 1. 获取年龄
age = int(input('请您输入年龄：'))

# 2. 判断年龄
if age >= 18:
    # 3. 条件满足时给出提示
    print('可以进入网吧了~')
```



**流程图**：

text

```
开始
  │
  ▼
输入年龄
  │
  ▼
age >= 18 ? ──否──→ 结束
  │是
  ▼
输出"可以进入网吧了~"
  │
  ▼
结束
```

## 二、`if-else` 语句

### 基本格式

python

```
if 条件判断:
    条件满足时，执行的代码
else:
    条件不满足时，执行的代码
```



### 示例：成年判断（带不满足的情况）

python

```
# 需求：年龄大于等于18可以进入网吧，否则回家写作业

# 1. 获取年龄
age = int(input('请您输入年龄：'))

# 2. 判断年龄
if age >= 18:
    print('可以进入网吧了~')
else:
    print('回家写作业吧~')
```



**流程图**：

text

```
开始
  │
  ▼
输入年龄
  │
  ▼
age >= 18 ? ──是──→ 输出"可以进入网吧"
  │否
  ▼
输出"回家写作业"
  │
  ▼
结束
```

## 三、`if-elif-else` 语句（多条件判断）

### 基本格式

python

```
if 条件判断1:
    条件1满足时，执行的代码
elif 条件判断2:
    条件2满足时，执行的代码
elif 条件判断3:
    条件3满足时，执行的代码
...
else:
    所有条件都不满足时，执行的代码
```



> 💡 `elif` 是 `else if` 的缩写，可以有多个。

### 示例：成绩等级评定

python

```
# 需求：根据分数评定等级
# 90分以上：优
# 80-89分：良
# 60-79分：中
# 60分以下：差

score = int(input('请输入成绩：'))

if score >= 90:
    print(f'成绩：{score}，等级：优')
elif score >= 80:
    print(f'成绩：{score}，等级：良')
elif score >= 60:
    print(f'成绩：{score}，等级：中')
else:
    print(f'成绩：{score}，等级：差')
```

## 四、`if` 语句嵌套

### 基本格式

python

```
if 条件1:
    满足条件1执行的代码
    if 条件2:
        满足条件2执行的代码
    else:
        不满足条件2执行的代码
else:
    不满足条件1执行的代码
```



### 示例：成绩等级（带有效性校验）

python

```
# 需求：判断成绩等级，先判断成绩是否有效

score = int(input('请输入成绩：'))

# 先判断成绩是否有效
if score < 0 or score > 100:
    print('您输入的成绩无效！')
else:
    # 成绩有效，再判断等级
    if score >= 90:
        print(f'成绩：{score}，等级：优')
    elif score >= 80:
        print(f'成绩：{score}，等级：良')
    elif score >= 60:
        print(f'成绩：{score}，等级：中')
    else:
        print(f'成绩：{score}，等级：差')
```

## 五、综合案例1：登录系统

python

```
# 需求：实现简单的登录验证

# 1. 注册（这里写死，实际开发中会从数据库读取）
name = 'admin'
pwd = '123456'

# 2. 登录（获取用户输入）
user_name = input('请您输入用户名：')
user_pwd = input('请您输入密码：')

# 3. 判断
if user_name == name and user_pwd == pwd:
    print('登录成功~，跳转首页...')
else:
    print('登录失败~，请重新操作')
```



**知识点**：

- `and` 逻辑运算符：两个条件同时满足才为 True
- 字符串比较：`==` 判断两个字符串是否相等

## 六、`random` 随机数模块

### 概念

> **函数**：提前组织好的、可以重复使用的、具有特定功能的代码块。

### 使用步骤

python

```
# 第1步：导入 random 包
import random

# 第2步：生成随机数
# random.randint(a, b) 生成 [a, b] 范围内的随机整数（左闭右闭）
sjs = random.randint(1, 10)
print(sjs)
```



> 💡 **小技巧**：按住 `Ctrl` + 鼠标左键点击函数名，可以查看源代码！

## 七、综合案例2：猜数字游戏

### 需求：猜一次

python

```
# 需求：随机产生一个1-10之间的数字，用户来猜，最多猜1次

import random

# 1. 获取随机数（范围1-10）
sjs = random.randint(1, 10)
print(f'只有内部人员知道的随机数是：{sjs}')  # 调试用

# 2. 获取用户猜的数
cds = int(input('请您输入您猜的数（范围1-10）：'))

# 3. 判断并给出提示
if cds < 1 or cds > 10:
    print('您猜的数无效，请仔细查看提示！')
else:
    if cds == sjs:
        print('猜对了！')
    elif cds > sjs:
        print('猜大了')
    else:
        print('猜小了')
```



### 需求：猜三次（了解即可）

python

```
# 需求：随机产生一个1-10之间的数字，用户来猜，最多猜3次

import random

# 1. 获取随机数
sjs = random.randint(1, 10)
print(f'只有内部人员知道的随机数是：{sjs}')  # 调试用

# 第一次猜测
cds = int(input('请您输入您猜的数（范围1-10）：'))

if cds < 1 or cds > 10:
    print('您猜的数无效！')
else:
    if cds == sjs:
        print('猜对了，程序结束')
    else:
        # 第一次猜错，给出提示
        if cds > sjs:
            print('猜大了，请继续猜')
        else:
            print('猜小了，请继续猜')
        
        # 第二次猜测
        cds = int(input('请您输入您猜的数（范围1-10）：'))
        
        if cds < 1 or cds > 10:
            print('您猜的数无效！')
        else:
            if cds == sjs:
                print('猜对了，程序结束')
            else:
                # 第二次猜错，给出提示
                if cds > sjs:
                    print('猜大了，请继续猜')
                else:
                    print('猜小了，请继续猜')
                
                # 第三次猜测
                cds = int(input('请您输入您猜的数（范围1-10）：'))
                
                if cds < 1 or cds > 10:
                    print('您猜的数无效！')
                else:
                    if cds == sjs:
                        print('猜对了，程序结束')
                    else:
                        if cds > sjs:
                            print('猜大了，三次机会用完，程序结束')
                        else:
                            print('猜小了，三次机会用完，程序结束')
```



> 💡 **思考**：上面猜三次的代码出现了大量重复，有没有更好的办法？下一节的「循环」可以解决这个问题！

## 知识点总结

### 条件判断关键字

| 关键字 | 说明                                 |
| :----- | :----------------------------------- |
| `if`   | 如果条件成立，执行代码块             |
| `elif` | 如果前面的条件不成立，再判断这个条件 |
| `else` | 所有条件都不成立时执行               |

### 比较运算符

| 运算符 | 含义     | 示例        |
| :----- | :------- | :---------- |
| `==`   | 等于     | `age == 18` |
| `!=`   | 不等于   | `age != 18` |
| `>`    | 大于     | `age > 18`  |
| `<`    | 小于     | `age < 18`  |
| `>=`   | 大于等于 | `age >= 18` |
| `<=`   | 小于等于 | `age <= 18` |

### 逻辑运算符

| 运算符 | 含义                   | 示例                      |
| :----- | :--------------------- | :------------------------ |
| `and`  | 且（两个条件都要满足） | `age >= 18 and age <= 60` |
| `or`   | 或（满足其中一个即可） | `age < 18 or age > 60`    |
| `not`  | 非（取反）             | `not age >= 18`           |

### 随机数模块

| 代码                   | 说明                         |
| :--------------------- | :--------------------------- |
| `import random`        | 导入 random 模块             |
| `random.randint(a, b)` | 生成 [a, b] 范围内的随机整数 |
