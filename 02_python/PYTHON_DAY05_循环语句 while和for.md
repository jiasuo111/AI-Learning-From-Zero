# Python 循环语句

> 循环让计算机能够重复执行相同的代码

------

## 一、`while` 循环

### 基本格式

python

```
# 完整格式
初始变量
while 条件判断:
    循环体（要重复执行的代码）
    条件控制

# 简化格式
while 条件判断:
    循环体
```



> ⚠️ **注意**：如果条件判断的结果恒为 `True`，会出现**死循环**（无限循环）！

### 流程图

text

```
开始
  │
  ▼
初始化变量
  │
  ▼
条件判断 ──否──→ 结束
  │是
  ▼
执行循环体
  │
  ▼
条件控制（改变变量）
  │
  └──────→ 回到条件判断
```



------

### 示例1：打印 1-100

python

```
# 需求：在控制台打印出 1-100

# 定义变量并赋初始值
i = 1

# while 条件判断
while i <= 100:
    # 循环体
    print(i)
    # 条件控制
    i += 1
```



------

### 示例2：打印 1-100 的偶数

python

```
# 方式1：步长法（每次+2）
i = 0
while i <= 100:
    print(i)
    i += 2

print('------------------------------------')

# 方式2：判断法（判断是否是偶数）
i = 1
while i <= 100:
    if i % 2 == 0:  # 如果是偶数
        print(i)
    i += 1
```



------

### 示例3：求 1-100 的总和

python

```
# 需求：while 循环求 1-100 的和

# 1. 循环初始变量
i = 1

# 循环外定义求和初始变量
total = 0

# 2. while 条件判断
while i <= 100:
    # 3. 循环体：累加
    total += i  # total = total + i
    # 4. 条件控制
    i += 1

# 循环外使用最终结果
print(f"1-100的和为：{total}")  # 5050
```

### 示例4：猜数字游戏（3次机会）

python

```
# 需求：随机产生一个1-100之间的数字，用户来猜，最多猜3次

import random

# 1. 获取随机数
secret = random.randint(1, 100)
print(f'只有内部人员知道的随机数是：{secret}')  # 调试用

# 2. 循环3次
i = 1
while i <= 3:
    # 获取用户猜的数
    guess = int(input('请您输入您猜的数（范围1-100）：'))
    
    # 判断并给出提示
    if guess < 1 or guess > 100:
        print('您猜的数无效，请仔细查看提示！')
    else:
        if guess == secret:
            print('猜对了！')
            break  # 跳出循环
        elif guess > secret:
            print('猜大了')
        else:
            print('猜小了')
    
    i += 1
```

### 示例6：打印九九乘法表

python

```
# 需求：打印九九乘法表

# 外层循环控制行（1-9）
i = 1
while i <= 9:
    # 内层循环控制列（1-i）
    j = 1
    while j <= i:
        print(f"{j}*{i}={j * i}", end='\t')  # end='\t' 不换行，用制表符分隔
        j += 1
    # 每行结束后换行
    print()
    i += 1
```

## 二、`for` 循环

### 基本格式

python

```
# 遍历数据集
for 临时变量 in 待处理的数据集:
    循环体

# 配合 range 使用
for 临时变量 in range(起始值, 结束值, 步长):
    循环体
```



**`range()` 参数说明**：

| 参数 | 说明             | 示例                          |
| :--- | :--------------- | :---------------------------- |
| `x`  | 起始值（默认 0） | `range(5)` → 0,1,2,3,4        |
| `y`  | 结束值（不包含） | `range(1, 5)` → 1,2,3,4       |
| `z`  | 步长（默认 1）   | `range(1, 10, 2)` → 1,3,5,7,9 |

### 示例1：遍历字符串

python

```
# 需求：把字符串 "itcast" 的每个字符打印出来
for char in "itcast":
    print(char)
```



**输出**：

text

```
i
t
c
a
s
t
```

### 示例2：打印 1-100

python

```
# 需求：for 循环打印 1-100
```

## 三、`break` 和 `continue`

### 区别对比

| 关键字     | 作用                     | 比喻                   |
| :--------- | :----------------------- | :--------------------- |
| `break`    | 跳出/结束当前循环        | 中途下车，不再继续     |
| `continue` | 跳过本次循环，进入下一次 | 跳过这一层，继续下一层 |

> ⚠️ **注意**：`break` 和 `continue` 只能作用于**当前所在的循环**（多层循环时只影响内层）。

------

### 示例1：`break` - 中途停止

python

```
# 需求：坐电梯到20层，但到第5层就下电梯

for i in range(1, 21):
    print(f'{i}层到了~')
    if i == 5:
        break  # 到第5层就结束循环
```



**输出**：

text

```
1层到了~
2层到了~
3层到了~
4层到了~
5层到了~
```



------

### 示例2：`continue` - 跳过某些层

python

```
# 需求：坐电梯到20层，但不想听到4层、14层、18层的播报

for i in range(1, 21):
    if i == 4 or i == 14 or i == 18:
        continue  # 跳过本次循环，继续下一次
    print(f'{i}层到了~')
```



**输出**：

text

```
1层到了~
2层到了~
3层到了~
5层到了~
6层到了~
...（省略）
```

## 四、`while` vs `for` 对比

| 对比项     | `while` 循环             | `for` 循环        |
| :--------- | :----------------------- | :---------------- |
| 适用场景   | 不知道循环次数           | 知道循环次数      |
| 条件控制   | 需要手动控制             | 自动控制（range） |
| 死循环风险 | 较高（容易忘记条件控制） | 较低              |
| 代码简洁度 | 相对繁琐                 | 更简洁            |

### 选择建议

python

```
# 知道循环次数 → 用 for
for i in range(10):
    print(i)

# 不知道循环次数（如猜数字直到猜对）→ 用 while
while True:
    guess = int(input("猜数字："))
    if guess == secret:
        break
```

## 知识点总结

### `while` 循环结构

text

```
初始化变量
while 条件:
    循环体
    条件控制
```



### `for` 循环结构

text

```
for 变量 in 可迭代对象:
    循环体
```



### `range()` 函数

| 调用方式         | 生成序列         | 示例                          |
| :--------------- | :--------------- | :---------------------------- |
| `range(n)`       | 0 到 n-1         | `range(5)` → 0,1,2,3,4        |
| `range(m, n)`    | m 到 n-1         | `range(2, 5)` → 2,3,4         |
| `range(m, n, s)` | m 到 n-1，步长 s | `range(1, 10, 2)` → 1,3,5,7,9 |

### 循环控制关键字

| 关键字     | 作用                     |
| :--------- | :----------------------- |
| `break`    | 跳出整个循环             |
| `continue` | 跳过本次循环，继续下一次 |
