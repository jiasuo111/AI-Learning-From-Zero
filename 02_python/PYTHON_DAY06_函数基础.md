# Python 函数

> 函数是「一次编写，多次使用」的代码块。把重复的代码封装成函数，让程序更简洁、更易维护。

---

## 一、函数的核心概念

### 函数的格式

```python
def 函数名(形参):
    函数体
    return 返回值
```

### 函数的调用

```python
变量 = 函数名(实参)
```

---

## 二、函数的重要规则

| 规则                   | 说明                                       |
| ---------------------- | ------------------------------------------ |
| **先定义，再调用**     | 函数必须定义后才能使用                     |
| **不调用不执行**       | 定义函数只是「准备」，调用才「执行」       |
| **每调用一次执行一次** | 可以多次调用同一个函数                     |
| **形参与实参对应**     | 定义时有形参，调用时必须传入对应数量的实参 |
| **返回值建议接收**     | 有返回值时，建议用变量接收                 |
| **无返回值返回 None**  | 没有 `return` 时，函数默认返回 `None`      |

## 三、函数的四种形态

### 1. 无参无返回值

```python
# 定义函数
def get_sum():
    a = 1
    b = 2
    result = a + b
    print(result)

# 调用函数
get_sum()  # 输出：3
get_sum()  # 再调用一次，输出：3
```

**特点**：
- 不需要传入数据
- 不返回数据（实际返回 `None`）

---

### 2. 有参无返回值

```python
# 定义函数
def get_sum(a, b):
    result = a + b
    print(result)

# 调用函数
get_sum(1, 2)  # 输出：3
get_sum(3, 4)  # 输出：7
```

**特点**：
- 需要传入数据（形参 `a`, `b`）
- 不返回数据，直接打印结果

---

### 3. 无参有返回值

```python
# 定义函数
def get_sum():
    a = 1
    b = 2
    result = a + b
    return result

# 调用函数
print(get_sum() + 10)  # 输出：13
```

**特点**：
- 不需要传入数据
- 返回计算结果，可以继续参与运算

---

### 4. 有参有返回值（最常用）

```python
# 定义函数
def get_sum(a, b):
    result = a + b
    return result

# 调用函数
h1 = get_sum(1, 2)      # h1 = 3
h2 = get_sum(h1, 10)    # h2 = 13
print(h2)               # 输出：13
```

**特点**：
- 需要传入数据
- 返回计算结果
- **最灵活、最常用**

## 四、函数的参数详解

### 示例：实现两个数的求和

```python
# 需求1：直接实现（没有用函数）
a = 1
b = 2
result = a + b
print(result)

# 需求2：用函数实现（无参无返回值）
def get_sum():
    a = 1
    b = 2
    result = a + b
    print(result)

get_sum()

# 需求3：用函数实现（有参无返回值）
def get_sum(a, b):
    result = a + b
    print(result)

get_sum(1, 2)
get_sum(3, 4)
```

## 五、函数的返回值详解

### `return` 的作用

| 作用     | 说明                                   |
| -------- | -------------------------------------- |
| **主职** | 结束函数（函数执行到 `return` 就停止） |
| **兼职** | 把后面的值返回给调用者                 |

### 示例：有参有返回值

```python
def get_sum(a, b):
    result = a + b
    return result

# 调用并接收返回值
h1 = get_sum(1, 2)   # h1 = 3
h2 = get_sum(h1, 10) # h2 = 13
print(h2)            # 输出：13
```

## 六、`None` 类型

### 什么是 `None`？

> `None` 是 Python 中的特殊字面量，表示「空」、「无实际意义」。

- 类型：`<class 'NoneType'>`
- 无返回值的函数，实际上就是返回 `None`

### 示例：没有 `return` 的函数

```python
def show():
    print(3)
    # 系统自动补充：return None

# 正确调用
show()  # 输出：3

print('---------------------')

# 错误调用（不建议接收返回值）
a = show()  # a = None
print(a)    # 输出：None
print(a + 10)  # 报错！None 不能和整数相加
```

> ⚠️ **注意**：如果函数没有返回值，就不要用变量去接收！否则拿到的是 `None`，可能引发错误。

## 七、函数完整示例对比

### 四种形态对比表

| 形态         | 定义格式       | 调用格式      | 使用场景                   |
| ------------ | -------------- | ------------- | -------------------------- |
| 无参无返回值 | `def f():`     | `f()`         | 执行固定操作，如打印       |
| 有参无返回值 | `def f(a, b):` | `f(1, 2)`     | 根据输入执行操作           |
| 无参有返回值 | `def f():`     | `x = f()`     | 返回固定计算结果           |
| 有参有返回值 | `def f(a, b):` | `x = f(1, 2)` | 根据输入返回结果（最常用） |

### 代码示例

```python
# 1. 无参无返回值
def say_hello():
    print("Hello!")

say_hello()

# 2. 有参无返回值
def greet(name):
    print(f"Hello, {name}!")

greet("张三")

# 3. 无参有返回值
def get_pi():
    return 3.14159

pi = get_pi()
print(pi)

# 4. 有参有返回值（推荐）
def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8
```

## 知识点总结

### 函数定义与调用

```python
# 定义
def 函数名(参数):
    代码块
    return 返回值

# 调用
函数名(参数)           # 无返回值时
变量 = 函数名(参数)     # 有返回值时
```

### 形参与实参

| 概念 | 说明             | 位置       |
| ---- | ---------------- | ---------- |
| 形参 | 形式参数，占位符 | 函数定义时 |
| 实参 | 实际参数，具体值 | 函数调用时 |

### `return` 要点

- `return` 会**立即结束**函数
- `return` 后面的值返回给调用者
- 没有 `return` 时，函数返回 `None`

### `None` 要点

- 表示「空」、「无意义」
- 不能与数值类型进行运算
- 常用于判断（如 `if result is None:`）
