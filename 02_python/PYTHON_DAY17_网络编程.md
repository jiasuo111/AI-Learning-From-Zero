## 一、计算机网络概述

### 1.1 网络的概念

**网络**：将具有独立功能的多台计算机通过通信线路和通信设备连接起来，在网络管理软件及网络通信协议下，实现资源共享和信息传递的虚拟平台。

### 1.2 为什么要学习网络编程？

学习网络编程的目的是能够编写基于网络通信的软件或程序，例如：

- 聊天软件（微信、QQ）
- 文件传输工具
- 远程控制软件
- Web 服务器

## 二、IP 地址

### 2.1 什么是 IP 地址？

> **IP 地址**：分配给网络设备上网使用的数字标签，它能够标识网络中唯一的一台设备。

**作用**：通过 IP 地址找到网络中唯一一台设备，然后跟这个设备进行数据通信。

### 2.2 IP 地址的表现形式

text

```
192.168.1.1
```



| 位      | 范围    |
| :------ | :------ |
| 第1位   | 1 ~ 223 |
| 第2-4位 | 0 ~ 255 |

### 2.3 IP 地址分类

| 类型     | 说明                                         |
| :------- | :------------------------------------------- |
| **IPv4** | 目前使用的 IP 地址（如 `192.168.1.1`）       |
| **IPv6** | 未来使用的 IP 地址（解决 IPv4 不够用的问题） |

------

## 三、端口与端口号

### 3.1 端口的作用

> **端口**：传输数据的通道。每运行一个程序都会有一个端口，想要给对应的程序发送数据，找到对应的端口即可。

### 3.2 端口号

操作系统为每个端口分配一个编号，即**端口号**。通过 IP 地址找到设备，通过端口号找到端口，通过端口把数据传给应用程序。

### 3.3 端口号分类

| 类型           | 范围         | 说明                                            |
| :------------- | :----------- | :---------------------------------------------- |
| **知名端口号** | 0 ~ 1023     | 固定分配给特定服务（如 80 → HTTP，443 → HTTPS） |
| **动态端口号** | 1024 ~ 65535 | 给开发者的应用程序使用                          |

> 💡 **建议**：开发时端口号设置为 8000 以后，避免与知名端口冲突。

### 3.4 通信流程

text

```
IP 地址（找到设备）→ 端口号（找到端口）→ 端口（传输数据）→ 应用程序
```

## 四、TCP 协议

### 4.1 为什么需要传输协议？

通过 IP 地址和端口号能找到目标应用程序，但数据不能随便发送，还需要选择**传输协议**，保证程序之间按照指定的规则进行数据通信。

### 4.2 什么是 TCP？

> **TCP（Transmission Control Protocol，传输控制协议）**：一种**面向连接的、可靠的、基于字节流**的传输层通信协议。

**TCP 通信步骤**：

1. 创建连接（三次握手）
2. 传输数据
3. 关闭连接（四次挥手）

> 💡 **比喻**：TCP 通信就像「打电话」——需要先拨号建立连接，通话结束后挂断。

### 4.3 TCP 的特点

| 特性         | 说明                             |
| :----------- | :------------------------------- |
| **面向连接** | 通信前必须建立连接，结束后断开   |
| **可靠传输** | 保证数据完整到达                 |
| **发送应答** | 每个报文段都需要得到应答         |
| **超时重传** | 超时未应答则重新发送             |
| **错误校验** | 校验数据是否有错误               |
| **流量控制** | 避免发送过快导致接收方来不及处理 |

### 4.4 TCP vs UDP

| 对比项   | TCP                      | UDP                  |
| :------- | :----------------------- | :------------------- |
| 可靠性   | 可靠（100%传输）         | 不可靠（可能丢包）   |
| 速度     | 较慢                     | 较快                 |
| 适用场景 | 文件传输、网页访问、邮件 | 视频通话、直播、语音 |

## 五、Python 编码转换

### 5.1 为什么需要编码转换？

在网络传输中，数据都是以**二进制**形式传输的。发送前需要将字符串编码为二进制数据，接收后再解码。

text

```
字符串（如 "Hello"）→ encode() → 二进制数据 → 网络传输 → decode() → 字符串
```



### 5.2 编码转换方法

| 方法       | 说明                  | 语法                             |
| :--------- | :-------------------- | :------------------------------- |
| `encode()` | 编码：字符串 → 二进制 | `str.encode(encoding='utf-8')`   |
| `decode()` | 解码：二进制 → 字符串 | `bytes.decode(encoding='utf-8')` |

### 5.3 示例

python

```
# 编码（字符串 → 二进制）
msg = "I Love Python"
binary_data = msg.encode(encoding='utf-8')
print(binary_data)  # b'I Love Python'

# 解码（二进制 → 字符串）
original = binary_data.decode(encoding='utf-8')
print(original)  # I Love Python
```

## 七、TCP 客户端开发

### 7.1 开发流程（五步走）

text

```
┌─────────────────────────────────────────────────────────┐
│  1. 创建客户端套接字对象                                    │
│       ↓                                                 │
│  2. 和服务端套接字建立连接                                  │
│       ↓                                                 │
│  3. 发送数据                                             │
│       ↓                                                 │
│  4. 接收数据                                             │
│       ↓                                                 │
│  5. 关闭客户端套接字                                       │
└─────────────────────────────────────────────────────────┘
```



### 7.2 代码实现

python

```
import socket

if __name__ == '__main__':
    # 1. 创建客户端套接字对象（IPv4，TCP）
    tcp_client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    
    # 2. 和服务端建立连接（参数是元组：IP地址, 端口号）
    tcp_client_socket.connect(("192.168.31.181", 8080))
    
    # 3. 发送数据（需要编码为二进制）
    tcp_client_socket.send('Hello, Server!'.encode(encoding='utf-8'))
    
    # 4. 接收数据（1024 表示一次最多接收 1024 字节）
    recv_data = tcp_client_socket.recv(1024).decode('utf-8')
    print(f'收到服务端消息：{recv_data}')
    
    # 5. 关闭套接字
    tcp_client_socket.close()
```



### 7.3 Socket 常用方法

| 方法                                  | 说明            |
| :------------------------------------ | :-------------- |
| `socket.socket(AF_INET, SOCK_STREAM)` | 创建 TCP 套接字 |
| `connect((ip, port))`                 | 连接服务器      |
| `send(data)`                          | 发送数据        |
| `recv(buffer_size)`                   | 接收数据        |
| `close()`                             | 关闭套接字      |

## 八、TCP 服务端开发

### 8.1 开发流程（七步走）

text

```
┌─────────────────────────────────────────────────────────┐
│  1. 创建服务端套接字对象                                    │
│       ↓                                                 │
│  2. 绑定 IP 地址和端口号                                   │
│       ↓                                                 │
│  3. 设置监听（被动模式）                                    │
│       ↓                                                 │
│  4. 等待客户端连接（阻塞等待）                               │
│       ↓                                                 │
│  5. 接收数据                                             │
│       ↓                                                 │
│  6. 发送数据                                             │
│       ↓                                                 │
│  7. 关闭套接字                                           │
└─────────────────────────────────────────────────────────┘
```



### 8.2 代码实现

python

```
import socket

if __name__ == '__main__':
    # 1. 创建服务端套接字对象
    tcp_server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    
    # 2. 绑定 IP 地址和端口号（空字符串表示绑定本机所有网卡）
    tcp_server_socket.bind(("", 8888))
    
    # 3. 开启监听（128 表示最大等待连接数）
    tcp_server_socket.listen(128)
    
    print("服务端启动，等待连接...")
    
    # 4. 等待客户端连接（阻塞，返回新的套接字和客户端地址）
    conn_socket, client_addr = tcp_server_socket.accept()
    print(f'客户端 {client_addr} 已连接')
    
    # 5. 接收数据
    recv_data = conn_socket.recv(1024)
    print(f'收到消息：{recv_data.decode("utf-8")}')
    
    # 6. 发送数据
    conn_socket.send("消息已收到".encode('utf-8'))
    
    # 7. 关闭套接字
    conn_socket.close()
    tcp_server_socket.close()
```



### 8.3 服务端方法说明

| 方法               | 说明                                         |
| :----------------- | :------------------------------------------- |
| `bind((ip, port))` | 绑定 IP 和端口                               |
| `listen(backlog)`  | 设置监听，backlog 是最大等待连接数           |
| `accept()`         | 等待客户端连接，返回（新套接字, 客户端地址） |

## 九、多客户端服务端开发

实际场景中，服务端需要同时处理多个客户端连接，需要使用循环来持续接受连接。

python

```
import socket

# 1. 创建套接字对象
tcp_server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. 绑定 IP 与端口
tcp_server_socket.bind(("", 8090))

# 3. 设置监听
tcp_server_socket.listen(128)

print("服务端启动，等待客户端连接...")

# 4. 循环等待客户端连接
while True:
    try:
        new_socket, client_addr = tcp_server_socket.accept()
        print(f'客户端 {client_addr} 已连接')
        
        # 循环处理单个客户端的多次请求
        while True:
            try:
                # 接收数据
                recv_data = new_socket.recv(1024)
                if not recv_data:
                    # 客户端正常关闭连接
                    print(f'{client_addr} 客户端已断开')
                    break
                    
                recv_msg = recv_data.decode('gbk')
                print(f'{client_addr}：{recv_msg}')
                
                # 发送响应
                response = input('服务器端消息：')
                new_socket.send(response.encode('gbk'))
                
            except ConnectionResetError:
                print(f'{client_addr} 客户端连接异常断开')
                break
        
        # 关闭与当前客户端的连接
        new_socket.close()
        
    except Exception as e:
        print(f'服务器出错：{e}')
        break

# 关闭服务端套接字
tcp_server_socket.close()
```

## 十、端口复用

服务端程序关闭后，端口可能不会立即释放，需要设置端口复用来解决。

python

```
import socket

tcp_server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 设置端口复用（必须在 bind 之前设置）
tcp_server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, True)

# 然后绑定端口
tcp_server_socket.bind(("", 8888))
```

## 十一、Socket 核心原理

### 11.1 `send()` 和 `recv()` 的工作原理

text

```
┌─────────────────┐                    ┌─────────────────┐
│     客户端       │                    │     服务端       │
│                 │      TCP连接       │                 │
│  ┌───────────┐  │                    │  ┌───────────┐  │
│  │ 发送缓冲区 │──┼────── 数据 ────────┼─→│ 接收缓冲区 │  │
│  └───────────┘  │                    │  └───────────┘  │
│       ↑         │                    │       ↓         │
│    send()       │                    │    recv()       │
└─────────────────┘                    └─────────────────┘
```



**关键点**：

- `send()` 将数据写入发送缓冲区，由操作系统负责发送
- `recv()` 从接收缓冲区读取数据，如果没有数据则阻塞等待
- 1024 表示一次最多读取 1024 字节，需要循环读取完整消息

### TCP 客户端 vs 服务端

| 角色       | 流程                                    | 核心方法                         |
| :--------- | :-------------------------------------- | :------------------------------- |
| **客户端** | 创建 → 连接 → 发送 → 接收 → 关闭        | `connect()`、`send()`、`recv()`  |
