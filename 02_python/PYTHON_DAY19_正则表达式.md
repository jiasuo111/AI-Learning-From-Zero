# Python 正则表达式

> 正则表达式是处理文本的利器，它可以用来查找、匹配、替换符合特定规则的字符串。无论是数据验证、文本提取还是内容过滤，正则表达式都能大显身手。

------

## 一、正则表达式概述

### 1.1 为什么需要正则表达式？

在实际开发中，经常需要查找符合某些复杂规则的字符串，例如：

- 邮箱地址（`user@example.com`）
- 手机号码（`13812345678`）
- IP 地址（`192.168.1.1`）
- 图片地址（`https://xxx.com/image.jpg`）

> 💡 **正则表达式**就是专门用来解决这类问题的强大工具。

### 1.2 什么是正则表达式？

> **正则表达式（Regular Expression）**：一种用于匹配字符串中字符组合的**模式**。它由普通字符和特殊字符（元字符）组成，形成了一种强大的文本处理工具。

**示例**：`0\d{2}-\d{8}` 这个正则表达式可以匹配座机号码，如 `010-12345678`。

**特点**：

| 特点     | 说明                                                  |
| :------- | :---------------------------------------------------- |
| 语法复杂 | 可读性较差，但功能强大                                |
| 通用性强 | 适用于多种编程语言（Python、Java、JavaScript、Go 等） |

### 1.3 正则表达式的功能

| 功能         | 说明                   | 示例                       |
| :----------- | :--------------------- | :------------------------- |
| **数据验证** | 检查字符串是否符合规则 | 表单验证（手机、邮箱、IP） |
| **数据检索** | 从文本中查找匹配内容   | 网页数据抓取               |
| **数据隐藏** | 隐藏敏感信息           | `135****6235`              |
| **数据过滤** | 替换或删除敏感词       | 敏感关键词过滤             |

## 三、正则表达式匹配方式

### 3.1 三种匹配方式对比

| 函数           | 匹配范围               | 返回值            | 特点             |
| :------------- | :--------------------- | :---------------- | :--------------- |
| `re.match()`   | 只能从**开头**开始匹配 | 匹配对象或 `None` | 只返回第一个     |
| `re.search()`  | **整个字符串**中搜索   | 匹配对象或 `None` | 只返回第一个     |
| `re.findall()` | **整个字符串**中搜索   | 列表              | 返回所有匹配结果 |

### 3.2 `re.match()` - 从头开始匹配

python

```
import re

# match 必须从开头匹配
result = re.match('itheima', 'itheima.com')

if result:
    print('匹配成功:', result.group())  # 匹配成功: itheima
else:
    print('匹配失败!')
```



### 3.3 `re.search()` - 搜索第一个匹配

python

```
import re

# search 可以在整个字符串中搜索
result = re.search('itheima', 'www.itheima.com')

if result:
    print('匹配成功:', result.group())  # 匹配成功: itheima
else:
    print('匹配失败!')
```



### 3.4 `re.findall()` - 搜索所有匹配

python

```
import re

# findall 返回所有匹配结果的列表
result = re.findall('itheima', 'www.itheimaitheima.com')

if result:
    print('匹配成功:', result)  # 匹配成功: ['itheima', 'itheima']
else:
    print('匹配失败!')
```

## 四、正则表达式匹配规则

### 4.1 匹配单个字符

| 元字符 | 说明                                              | 示例                        |
| :----- | :------------------------------------------------ | :-------------------------- |
| `.`    | 匹配任意 1 个字符（除了换行符 `\n`）              | `a.c` → `abc`               |
| `[]`   | 匹配中括号中的任意 1 个字符                       | `[abc]` → `a` 或 `b` 或 `c` |
| `\d`   | 匹配任意 1 个数字（0-9）                          | `\d` → `5`                  |
| `\D`   | 匹配任意 1 个非数字                               | `\D` → `a`                  |
| `\s`   | 匹配任意 1 个空白字符（空格、`\t`、`\n`）         | `\s` → ``                   |
| `\S`   | 匹配任意 1 个非空白字符                           | `\S` → `a`                  |
| `\w`   | 匹配任意 1 个单词字符（字母、数字、下划线、汉字） | `\w` → `a`、`1`、`_`、`中`  |
| `\W`   | 匹配任意 1 个非单词字符                           | `\W` → `@`、`#`、`$`        |

#### 示例代码

python

```
import re

def show(result):
    if result:
        print('匹配成功:', result.group())
    else:
        print('匹配失败!')

# . : 任意一个字符（除\n）
result = re.match('.inzi.6.6_帅.', 'binzi_666_帅气')
show(result)  # 匹配成功: binzi_666_帅气

# [] : 中括号中任意一个字符
result = re.match('[bB]inzi_666_帅气', 'binzi_666_帅气')
show(result)  # 匹配成功

# \d : 任意一个数字
result = re.match('binzi_\d\d\d_帅气', 'binzi_888_帅气')
show(result)  # 匹配成功

# \s : 任意一个空白
result = re.match('binzi_666\s帅气', 'binzi_666 帅气')
show(result)  # 匹配成功

# \w : 任意一个单词字符
result = re.match('\winzi\w6\w6_帅\w', 'binzi_666_帅气')
show(result)  # 匹配成功
```



### 4.2 匹配多个字符

| 元字符  | 说明                                | 示例                           |
| :------ | :---------------------------------- | :----------------------------- |
| `*`     | 匹配前一个字符出现 **0 次或无限次** | `ab*c` → `ac`、`abc`、`abbc`   |
| `+`     | 匹配前一个字符出现 **1 次或无限次** | `ab+c` → `abc`、`abbc`         |
| `?`     | 匹配前一个字符出现 **0 次或 1 次**  | `ab?c` → `ac`、`abc`           |
| `{n}`   | 匹配前一个字符出现 **n 次**         | `a{3}` → `aaa`                 |
| `{n,m}` | 匹配前一个字符出现 **n 到 m 次**    | `a{2,4}` → `aa`、`aaa`、`aaaa` |

#### 示例代码

python

```
# * : 0次或多次
result = re.match('t.*o', 'to')      # 匹配成功（中间0个字符）
result = re.match('t.*o', 'tbo')     # 匹配成功（中间1个字符）
result = re.match('张.*三', '张三')   # 匹配成功

# + : 1次或多次
result = re.match('t.+o', 'to')      # 匹配失败（需要至少1个字符）
result = re.match('张.+三', '张三')   # 匹配失败（需要至少1个字符）
result = re.match('t.+o', 'tbo')     # 匹配成功

# ? : 0次或1次
result = re.match('https?', 'http')   # 匹配成功
result = re.match('https?', 'https')  # 匹配成功

# {n} : 恰好n次
result = re.match('binzi_\d{3}_帅气', 'binzi_888_帅气')  # 匹配成功

# {n,m} : n到m次
result = re.match('[a-zA-Z0-9_]{8,10}', 'abcABC123')  # 匹配成功
```



### 4.3 匹配开头和结尾

| 元字符 | 说明           |
| :----- | :------------- |
| `^`    | 匹配字符串开头 |
| `$`    | 匹配字符串结尾 |

> 💡 `^` 和 `$` 通常配合使用，起到**严格限制**的作用。

python

```
# 不加 ^ 和 $：可能匹配到部分内容
result = re.match('[a-zA-Z0-9_]{6}', 'abc_123456')
print(result.group())  # abc_123（只匹配了前6位）

# 加上 ^ 和 $：严格限制整个字符串
result = re.match('^[a-zA-Z0-9_]{6}$', 'abc_123456')
show(result)  # 匹配失败（整个字符串不是恰好6位）

result = re.match('^[a-zA-Z0-9_]{6}$', 'abc123')
show(result)  # 匹配成功
```



### 4.4 匹配分组

| 元字符       | 说明                                     |
| :----------- | :--------------------------------------- |
| `|`          | 匹配左右任意一个表达式（或）             |
| `( )`        | 将括号中的内容作为一个分组，默认产生编号 |
| `\n`         | 根据分组编号 n 引用对应的分组            |
| `(?P<name>)` | 给分组起别名                             |
| `(?P=name)`  | 根据分组别名引用对应的分组               |

#### 示例代码

python

```
# | : 或的关系
# 需求：匹配 @163.com 或 @qq.com 或 @sina.com
result = re.match('^[a-zA-Z0-9_]{4,20}@(163|qq|sina)\.com$', 'binzi@qq.com')
show(result)  # 匹配成功

# 获取分组内容
print(result.group(0))  # binzi@qq.com（所有匹配内容）
print(result.group(1))  # qq（第一个分组的内容）

# \n : 引用分组编号
# 需求：匹配 <html>...</html>、<h1>...</h1> 等标签
result = re.match('<([a-zA-Z1-6]+)>.*</\\1>', '<html>标签内容</html>')
show(result)  # 匹配成功

# (?P<name>) 和 (?P=name) : 给分组起别名并引用
result = re.match('<(?P<tag>[a-zA-Z1-6]+)>.*</(?P=tag)>', '<html>标签内容</html>')
show(result)  # 匹配成功
```



### 4.5 特殊匹配

| 写法     | 说明                                   |
| :------- | :------------------------------------- |
| `[^...]` | 匹配不在中括号中的任意一个字符（取反） |

python

```
# [^] 表示取反
result = re.match('[^\d].*', 'hello')  # 匹配非数字开头
show(result)  # 匹配成功

# 等价写法
result = re.match('[\D].*', 'hello')
show(result)  # 匹配成功
```

## 五、贪婪模式 vs 非贪婪模式

### 5.1 概念

| 模式           | 说明                                   | 默认                   |
| :------------- | :------------------------------------- | :--------------------- |
| **贪婪模式**   | 在匹配成功的前提下，**尽可能多**地匹配 | `*`、`+` 默认是贪婪的  |
| **非贪婪模式** | 在匹配成功的前提下，**尽可能少**地匹配 | 在 `*`、`+` 后面加 `?` |

### 5.2 示例

python

```
import re

my_str = '<h1>编程语言</h1>此处省略很多内容<h1>python大数据</h1>'

# 贪婪模式：尽可能多地匹配
data = re.findall('<h1>.*</h1>', my_str)
print(data)  # ['<h1>编程语言</h1>此处省略很多内容<h1>python大数据</h1>']
print(len(data))  # 1

# 非贪婪模式：尽可能少地匹配
data = re.findall('<h1>.*?</h1>', my_str)
print(data)  # ['<h1>编程语言</h1>', '<h1>python大数据</h1>']
print(len(data))  # 2

# 提取标签中的内容
data = re.findall('<h1>(.*?)</h1>', my_str)
print(data)  # ['编程语言', 'python大数据']
```

## 六、正则修饰符

| 修饰符 | 说明                       |
| :----- | :------------------------- |
| `re.I` | 匹配时**不区分大小写**     |
| `re.S` | 让 `.` 可以匹配换行符 `\n` |

### 示例

python

```
import re

# re.I : 不区分大小写
data = re.findall('^a8D9$', 'A8d9', re.I)
print(data)  # ['A8d9']

# re.S : . 可以匹配换行符
my_str = '123\n456\n789'
data = re.match('.{7}', my_str, re.S)
print(data.group())  # 123\n456
```

## 七、综合练习

python

```
import re

def show(data):
    if data:
        print('匹配成功:', data.group())
    else:
        print('匹配失败!')

# 1. 匹配微博中的话题，例如：#幸福是奋斗出来的#
result = re.match('#.+#', '#幸福是奋斗出来的#')
show(result)

# 2. 匹配11位手机号码，例如：18866668888
result = re.match('^1[0-9]{10}$', '18866668888')
show(result)

# 3. 匹配163邮箱地址，@符号之前有4到20位，例如：hello@163.com
# 注意：. 是特殊字符，需要转义 \.
result = re.match('^[a-zA-Z0-9_]{4,20}@163\.com$', 'binzi@163.com')
show(result)
```

## 知识点总结

### re 模块函数速查表

| 函数        | 匹配范围   | 返回值        | 使用场景           |
| :---------- | :--------- | :------------ | :----------------- |
| `match()`   | 开头       | 匹配对象/None | 验证整个字符串格式 |
| `search()`  | 整个字符串 | 匹配对象/None | 查找第一个匹配     |
| `findall()` | 整个字符串 | 列表          | 查找所有匹配       |

### 常用元字符速查表

| 类别   | 元字符  | 说明                           |
| :----- | :------ | :----------------------------- |
| 单字符 | `.`     | 任意字符（除\n）               |
|        | `\d`    | 数字                           |
|        | `\w`    | 单词字符（字母、数字、下划线） |
|        | `\s`    | 空白字符                       |
| 数量   | `*`     | 0次或多次                      |
|        | `+`     | 1次或多次                      |
|        | `?`     | 0次或1次                       |
|        | `{n}`   | 恰好n次                        |
|        | `{n,m}` | n到m次                         |
| 位置   | `^`     | 开头                           |
|        | `$`     | 结尾                           |
| 分组   | `|`     | 或                             |
|        | `( )`   | 分组                           |
|        | `\n`    | 引用第n组                      |

### 贪婪与非贪婪

text

```
贪婪模式：.*   .+   → 尽可能多匹配
非贪婪模式：.*?  .+? → 尽可能少匹配
```



### 修饰符

| 修饰符 | 作用           |
| :----- | :------------- |
| `re.I` | 不区分大小写   |
