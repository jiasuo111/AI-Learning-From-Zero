# 决策树

> 决策树是机器学习中最直观、最易理解的算法之一。它模拟人类做决策的方式，通过一系列「是/否」问题来得出结论。


## 一、课程引入

### 1.1 先看一个例子

假设你现在在纠结：“今天要不要去打球？”

你可能下意识地开始盘算：
```



今天天气怎么样？ → 晴天
↓
温度合适吗？ → 26℃，舒服
↓
有没有人一起去？ → 有！
↓
结论：去打球！

text

```
这个过程，就是一颗**决策树**。

### 1.2 什么是决策树？

决策树是一种树形结构，机器学习里的决策树，就是把这套逻辑教给计算机：

- 每个**内部节点** → 一个判断（“天气好吗？”）
- 每个**分支** → 一个结果（“晴天”或“雨天”）
- 每个**叶子节点** → 最终结论（“去打球”或“不去”）

> 专业定义：决策树是一种**监督学习算法**，可用于**分类和回归**任务。它通过对特征进行一系列 if-else 判断，将数据划分成若干区域，每个区域对应一个预测结果。


## 二、核心思想

### 2.1 一句话概括

> 从根节点开始，每次选一个「最优特征」和「分裂点」，把数据分成两个或多个子集，递归重复，直到满足停止条件。

### 2.2 关键概念

| 概念 | 含义 |
|------|------|
| 根节点 | 树的第一层，包含全部数据 |
| 内部节点 | 对某个特征做判断，决定分支走向 |
| 叶子节点 | 最终决策结果（分类标签或预测值） |
| 分支 | 一次判断后划分出的子集 |
| 树的深度 | 从根节点到最远叶子节点的边数 |
| 纯度 | 节点中样本是否属于同一类（越纯越好） |

### 2.3 核心目标：提高「纯度」

每次切分之后，让子节点尽可能**纯**（尽量全是同一类）。

> 目标：左边一类，右边一类，不要混在一起。


## 三、分裂标准

> 核心问题：**每次该用哪个特征来分裂？** 不同算法有不同的评价指标。

### 3.1 决策树算法的两个层面

在深入分裂标准之前，先搞清楚两个容易混淆的概念：

| 概念 | 含义 |
|------|------|
| **分裂标准（准则）** | 每次分裂时，用哪个指标评价“这个特征好不好” |
| **算法（框架）** | 整棵树怎么构建（二叉树还是多叉树、怎么剪枝、如何处理连续值） |

> ID3、C4.5、CART 是**算法**；信息增益、基尼系数是它们各自采用的**分裂标准**。

### 3.2 分类树常用标准

#### ① 信息增益（ID3 算法使用）

用人话说就是：**“这次分裂，让我获得了多少信息？”**

- 节点越纯 → 信息越少（很确定）
- 节点越乱 → 信息越多（需要更多信息来确定）

> 一个箱子里全是红球 → “红球”这个信息量 = 0（不用猜）
> 红球蓝球各一半 → 信息量大（需要告诉你是“红”还是“蓝”）

**公式（用人话说）**：
> 信息增益 = 分裂前的混乱程度 − 分裂后的加权平均混乱程度

增益越大 → 这次分裂越好。

**例子**：判断学生是否逃课

- 父节点：10个学生，5人逃课，5人不逃课 → 混乱（各占一半）

- 分裂方案1：按“成绩”分
    - 成绩高的3人：1人逃课，2人不逃课 → 较纯
    - 成绩低的7人：4人逃课，3人不逃课 → 还是乱

- 分裂方案2：按“游戏时间”分
    - 打游戏多的5人：4人逃课，1人不逃课 → 很纯
    - 打游戏少的5人：1人逃课，4人不逃课 → 也很纯

**方案2 分裂后子节点更纯 → 信息增益更大 → 决策树会选择「游戏时间」作为分裂特征。**

#### ② 信息增益率（C4.5 算法使用）

- 解决了信息增益**偏向多取值特征**的问题
- 如果一个特征取值太多（如“学号”），信息增益会虚高，但它其实没意义

#### ③ 基尼系数（CART 算法默认使用）

用人话说：**“如果从节点里随机抽两个样本，他们是不同类的概率有多大？”**

- 概率越大 → 节点越乱 → 基尼系数越大
- 概率越小 → 节点越纯 → 基尼系数越小

> CART 默认用基尼系数（而不是信息增益），因为计算更简单，效果也很好。

### 3.3 回归树常用标准

| 标准 | 说明 |
|------|------|
| MSE（均方误差） | 最小化节点内样本的方差 |
| MAE（绝对误差） | 最小化绝对误差和 |


## 四、CART 算法

> CART = Classification And Regression Tree（分类与回归树）

### 4.1 特点

| 特点 | 说明 |
|------|------|
| 生成二叉树 | 每个节点只分裂成两个子节点（左/右），不允许多叉树 |
| 分类+回归 | 分类树用基尼系数，回归树用 MSE/MAE |
| 默认分裂标准 | 基尼系数（分类）/ MSE（回归） |
| 处理特征 | 可以处理连续特征和离散特征 |
| 剪枝 | 自带成本复杂度剪枝，通过 `ccp_alpha` 参数控制 |

### 4.2 与其他决策树算法对比

| 对比维度 | ID3 | C4.5 | CART |
|----------|-----|------|------|
| 树结构 | 多叉树 | 多叉树 | **二叉树** |
| 支持回归 | ❌ | ❌ | ✅ |
| 处理连续特征 | ❌ | ✅ | ✅ |
| 分裂标准 | 信息增益 | 信息增益率 | 基尼系数 / MSE |
| 剪枝方式 | 预剪枝 | 预剪枝 | 预剪枝 + 后剪枝 |
| sklearn 支持 | ❌ | ❌ | ✅（默认） |


## 五、剪枝（防止过拟合）

> 树长得太大，就会把训练数据里的“噪声”也学进去 → 过拟合。剪枝就是去掉一些不必要的分支，提高泛化能力。

### 5.1 预剪枝

在树生长过程中**提前停止分裂**。

常用手段：

| 方法 | 判断标准 |
|------|----------|
| 最大深度 | 树深度超过阈值，停止分裂 |
| 最小样本数 | 节点样本数少于阈值，停止分裂 |
| 最小不纯度下降 | 分裂带来的不纯度下降小于阈值，停止 |
| 验证集准确率 | 分裂后验证集准确率没有提升，停止 |

### 5.2 后剪枝

树完全长成后，**自底向上修剪**掉不必要的分支。

- 成本复杂度剪枝（CCP）：衡量剪掉子树后，损失增加与树复杂度减少的权衡
- 验证集准确率：剪掉后验证集准确率不降低，就剪掉

> 核心原则：剪掉后损失不显著增加（或泛化性能不下降）→ 就剪。


## 六、优缺点

### 优点

- ✅ **可解释性强**：能画出规则路径，老板也能看懂
- ✅ 不需要特征缩放（不敏感于尺度）
- ✅ 可处理数值型 + 分类型特征
- ✅ 对缺失值有一定容忍度
- ✅ 天然处理多分类问题

### 缺点

- ❌ 容易过拟合（需剪枝）
- ❌ 对数据微小变化敏感（不稳定）—— 数据稍有变化，树结构可能大变
- ❌ 倾向于选择取值较多的特征（信息增益时）
- ❌ 训练时容易偏向多数类（不平衡数据）
