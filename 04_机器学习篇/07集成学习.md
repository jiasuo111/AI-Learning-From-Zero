# 集成学习

> 一个人做决定容易偏颇，一群人投票往往更靠谱。集成学习就是这个道理——把多个模型组合起来，让它们“集体决策”，效果通常比单个模型更好。


## 一、课程引入

### 1.1 先看一个例子

假设你要判断“明天会不会下雨”：

- 你问了**气象台**：预报说有雨 → 信一点
- 你问了**农民伯伯**：看天色说有雨 → 信一点
- 你查了**手机App**：也说有雨 → 信一点
- 你看了**蚂蚁搬家**：嗯……也信一点

最后你综合所有人的意见：**大概率会下雨，带伞！**

> 这就是集成学习的思想：**三个臭皮匠，顶个诸葛亮。**

### 1.2 什么是集成学习？

集成学习是一种**组合多个基学习器**的机器学习方法，通过综合多个模型的预测结果，获得比单一模型更好的泛化性能。

> 用人话说：一个模型不准，那就多训练几个，然后让他们投票/平均，结果更可靠。


## 二、为什么集成学习有效？

| 作用 | 说明 |
|------|------|
| **降低方差** | 多个模型平均，减少对训练数据噪声的敏感度（Bagging） |
| **降低偏差** | 串行修正前一个模型的错误，逐步逼近真实函数（Boosting） |
| **防止局部最优** | 不同模型的决策边界不同，投票/平均后更稳定 |

## 四、Bagging

> Bagging = Bootstrap Aggregating（自助聚合）

### 4.1 核心思想

并行训练多个基学习器，每个基学习器使用**有放回采样**的训练子集，最后通过**投票（分类）** 或**平均（回归）** 输出。

### 4.2 工作流程
```



原始训练集（N 个样本）
│
├── 有放回采样 N 次 → 子集1 → 训练基模型1
├── 有放回采样 N 次 → 子集2 → 训练基模型2
├── 有放回采样 N 次 → 子集3 → 训练基模型3
└── ...（共 T 个模型）
│
├── 分类：投票（少数服从多数）
└── 回归：平均

text

```
### 4.3 特点

| 特点 | 说明 |
|------|------|
| **并行** | 各模型可独立训练，适合分布式计算 |
| **降低方差** | 模型平均后，对噪声和异常值更鲁棒 |
| **不易过拟合** | 多模型平均，单模型过拟合被抵消 |
| **基学习器** | 通常用强模型（如不剪枝的决策树） |

> 代表算法：**随机森林**（后面单独讲）


## 五、Boosting

### 5.1 核心思想

串行训练多个基学习器，**后一个模型修正前一个模型的错误**，最后加权投票输出。

### 5.2 工作流程
```



原始训练集
│
├── 训练基模型1 → 计算错误样本 → 给错误样本更高的权重
├── 训练基模型2（关注上一轮错误样本）→ 再计算错误 → 再调权重
├── 训练基模型3（关注前两轮累积错误）→ ...
└── ...
│
└── 加权投票输出

text

```
### 5.3 特点

| 特点 | 说明 |
|------|------|
| **串行** | 后一个模型依赖前一个模型的结果，难以并行 |
| **降低偏差** | 逐步逼近真实函数 |
| **容易过拟合** | 模型复杂、迭代次数多时会过拟合 |
| **基学习器** | 通常用弱模型（如浅层决策树、树桩） |

### 5.4 Boosting 家族演进
```



AdaBoost（1995）
↓
GBDT（1999，梯度提升决策树）
↓
XGBoost（2014）—— 工程优化 + 正则化 + 并行
↓
LightGBM（2017）—— 基于直方图 + 单边梯度采样（GOSS）
↓
CatBoost（2017）—— 原生支持类别特征 + 对称树

text

```
### 5.5 重要澄清

> ⚠️ 很多人以为 Boosting 整个流程都是串行的，但这是**错误的**！

**训练阶段**：串行，每个模型依赖前一个模型的结果

**预测阶段**：并行独立！每个模型的预测只依赖输入 x 和它自己的参数，完全不依赖其他模型。
```



预测阶段：每个模型独立计算自己的预测结果

输入 x ──┬── 模型1 ──→ 预测1
├── 模型2 ──→ 预测2
├── 模型3 ──→ 预测3
└── ...
│
↓
加权投票 → 最终结果

text

```
> 也就是说，预测时所有模型可以同时计算，不需要等待！这也意味着 Boosting 在预测时比训练时快得多。


## 六、Bagging vs Boosting

| 对比维度 | Bagging | Boosting |
|----------|---------|----------|
| 训练方式 | **并行** | **串行**（训练时） |
| 预测方式 | 并行 | 并行 |
| 样本采样 | 有放回采样 | 全量训练（加权） |
| 基学习器权重 | 相同权重 | 根据准确率加权 |
| 目标 | **降低方差** | **降低偏差** |
| 过拟合 | 不易过拟合 | 容易过拟合（需调参） |
| 基学习器 | 强模型（如不剪枝决策树） | 弱模型（如树桩、浅层树） |
| 代表算法 | 随机森林 | AdaBoost、XGBoost、LightGBM |


## 七、Stacking

### 7.1 核心思想

用多个基模型的**预测结果作为新特征**，再训练一个**元模型**进行最终预测。

> 用人话说：先让一群专家分别给出意见，然后让一个“总指挥”根据这些意见做最终判断。

### 7.2 工作流程
```



原始训练集
│
├── 训练基模型1 → 预测结果1
├── 训练基模型2 → 预测结果2
├── 训练基模型3 → 预测结果3
└── ...
│
↓ 基模型的预测结果作为新特征
│
新的训练集 [预测1, 预测2, 预测3, ..., 真实标签]
│
↓
训练元模型（如逻辑回归）
│
↓
最终预测

text

```
### 7.3 特点

| 特点 | 说明 |
|------|------|
| **层次结构** | 基模型（第一层）+ 元模型（第二层） |
| **可以融合异构模型** | 可以混合不同算法（如 SVM + 决策树 + 神经网络） |
| **效果好** | 通常比单一模型好 |
| **计算量大** | 需要训练多个模型，计算成本高 |
