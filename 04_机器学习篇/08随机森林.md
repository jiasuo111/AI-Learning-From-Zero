随机森林
	是什么
		随机森林是一种基于决策树的集成学习算法，通过构建多棵决策树并综合它们的预测结果来提升模型的准确性和鲁棒性。
		一句话：随机森林 = 多棵决策树 + 随机采样 + 随机特征 + 投票/平均。
		核心定位：随机森林是 Bagging 的最典型代表，用决策树作为基学习器，并加入了随机特征选择。
	核心思想
		随机森林的核心思想（两个随机）
		随机选择样本
			（Bootstrap）
			每棵树的训练集是从原始数据中有放回随机抽取的，大小与原始数据集相同。
			原始数据（N 个样本）
			    │
			    ├── 有放回采样 N 次 → 子集1 → 训练树1
			    ├── 有放回采样 N 次 → 子集2 → 训练树2
			    ├── 有放回采样 N 次 → 子集3 → 训练树3
			    └── ...
		特点
			特点	说明
			样本数	每棵树都是 N 个样本（可能有重复）
			未选中比例	约 37% 的样本不会出现（Out-of-Bag，可用于验证）
			作用	让树与树之间的训练数据不同 → 差异增大
		随机选择特征
			每棵树在分裂时，不是从所有特征中选最优，而是随机挑选一部分特征，再从这些特征中选最优分裂点。
		为什么必须随机选特征？
			如果只随机样本，不随机特征	加上随机特征
			每棵树仍然会选最强的几个特征	每棵树看到的特征子集不同
			树与树之间仍然高度相似	树与树之间差异更大
			Bagging 效果有限	Bagging 效果更好
	工作流程
		【训练阶段】
		原始训练集（N 样本，M 特征）
		    │
		    ├── 有放回采样 N 次 → 子集1 → 随机选 k 个特征 → 训练决策树1（不剪枝）
		    ├── 有放回采样 N 次 → 子集2 → 随机选 k 个特征 → 训练决策树2（不剪枝）
		    ├── 有放回采样 N 次 → 子集3 → 随机选 k 个特征 → 训练决策树3（不剪枝）
		    └── ...（共 T 棵树）
		

		【预测阶段】
		新样本 x
		    │
		    ├── 树1 预测 → 结果1
		    ├── 树2 预测 → 结果2
		    ├── 树3 预测 → 结果3
		    └── ...
		    │
		    ├── 分类：投票（少数服从多数）
		    └── 回归：平均
	随机森林的超参数
	优缺点
	Out-of-Bag（OOB）验证
		每棵树训练时，约 37% 的样本不会被选中（OOB 样本），这些样本可以用来验证该树。
		OOB 准确率 ≈ 使用验证集的准确率，不需要额外划分验证集。
	特征重要性评估
		方式							原理
		基于基尼系数（Gini Importance）		记录每个特征在所有树中分裂时带来的纯度提升，累加、平均
		基于准确率下降（Permutation Importance）	打乱某个特征的值，看模型准确率下降多少（下降越多，特征越重要）
	随机森林 vs 单棵决策树
		对比		单棵决策树	随机森林
		过拟合		容易		不易
		可解释性	好（可画树）	差（很多树）
		对噪声敏感	敏感		不敏感
		训练速度	快		慢（T 倍）
		预测速度	快		慢（T 倍）
		效果		一般		更好
	随机森林 vs XGBoost（面试常问）
		对比	随机森林	XGBoost
		集成方式	Bagging（并行）	Boosting（串行）
		树之间关系	独立训练	后一棵树修正前一棵的错误
		过拟合	不易	相对容易（需调参）
		训练速度	快（可并行）	慢（串行）
		效果	好	通常更好（尤其表格数据）
		适用场景	高维、噪声多	结构化表格数据
	总分总
		总
			随机森林是一种基于决策树的 Bagging 集成学习算法，通过随机样本采样和随机特征采样构建多棵决策树，最后投票或平均输出。
		分
			第一，两个随机
				一是有放回采样（Bootstrap），每棵树用不同的样本子集；二是随机特征选择，每次分裂只从随机抽取的部分特征中选最优。这两个随机让树与树之间差异更大，集成效果更好。
			训练与预测
				训练时多棵树独立并行构建；预测时分类用投票，回归用平均。OOB 样本可作为内置验证集。
			，优缺点
				训练时多棵树独立并行构建；预测时分类用投票，回归用平均。OOB 样本可作为内置验证集。
			与 XGBoost 的区别
				随机森林是 Bagging（并行），XGBoost 是 Boosting（串行）。随机森林更稳健、不易过拟合；XGBoost 精度更高、但调参更复杂。
		总
			随机森林是 Bagging 的代表算法，用“两个随机”让多棵决策树差异互补，是表格数据上效果好、省心的基线模型。
	TF-IDF 
		作用:文档向量化
		
		TF（Term Frequency）词频 + IDF（Inverse Document Frequency）逆文档频率
		衡量一个词在某篇文档里有多重要。
		TF 词频：词在当前文章出现多少次
			TF 只看当前单篇文档（单个样本），完全不碰其他文档
		IDF 逆文档频率：惩罚到处都有的通用词
			同一个词语，在整个数据集里只会算出唯一固定的 IDF 值，所有文档共用这一个 IDF；不同词语 IDF 互不相同。
		TF-IDF 最终值
			TFIDF(t,d)=TF(t,d)×IDF(t)
			每个词，对【当前这篇文档】的重要程度分数
		逻辑：
		本文频繁出现（TF 高）
		全局很少文档出现（IDF 高）
		→ 相乘后分数极高 = 本文核心关键词
		
		不同样本里的同一个词，分数 100% 不一样！
		2. 所以必须给每个样本一整份完整词汇表的分数
