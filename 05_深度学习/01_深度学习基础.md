# dl_01_深度学习基础



```
> 深度学习是机器学习的进阶，也是当前AI大模型的基础。本节帮你搞懂深度学习的核心概念，以及它和传统机器学习的区别。


## 一、什么是深度学习？

**深度学习是机器学习的一个分支**，以人工神经网络为核心结构，实现**自动提取数据特征**的算法。

用人话说：传统机器学习需要你手动告诉机器“看哪些特征”，深度学习让机器**自己学会看哪些特征**。


## 二、深度学习 vs 传统机器学习

### 2.1 一句话核心区别

> **传统ML：人工设计特征 → 模型训练**
> **深度学习：原始数据 → 模型自动提取特征 → 训练**

### 2.2 详细对比

| 对比维度 | 传统机器学习 | 深度学习 |
|----------|-------------|----------|
| 特征工程 | **人工设计**特征（提取、选择、组合） | **自动提取**层次化特征 |
| 数据量 | 小数据量表现好 | 大数据量优势明显 |
| 可解释性 | 较好（决策树、线性模型） | 较差（黑盒） |
| 算力要求 | 低（CPU即可） | 高（需要GPU） |
| 典型应用 | 表格数据、小规模分类 | 图像、语音、大模型 |

### 2.3 建模流程对比
```



传统机器学习：
原始数据 → 数据预处理 → 特征工程（人工） → 模型训练 → 预测

深度学习：
原始数据 → 数据预处理 → 神经网络自动提取特征 → 预测
└──── 特征工程自动化 ────┘

text

```
> 深度学习把特征工程自动化了，代价是：**需要更多数据、更高算力、更低可解释性。**


## 三、神经网络结构

### 3.1 基础结构：全连接网络（ANN）
```



输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
↓ ↓
权重 w₁ 权重 w₂

text

```
### 3.2 常见网络结构变种

| 网络结构 | 核心构件 | 一句话说明 | 适用场景 |
|----------|----------|------------|----------|
| **基础 ANN** | 全连接层 | 每个神经元与前后层全部相连 | 基础任务 |
| **CNN** | 卷积层 + 池化层 | 用卷积核滑动提取局部特征 | 图像领域 |
| **RNN** | 循环层 | 隐藏层有环状连接，记住历史信息 | 序列数据 |
| **Transformer** | 自注意力层 | 计算任意两个位置的关系 | 大模型基础 |

### 3.3 它们都叫“神经网络”的原因

所有神经网络都遵循同一个框架：
```



输入 → 加权求和 → 非线性激活 → 输出
↓
多层堆叠
↓
通过反向传播 + 梯度下降学习参数

text

```
> CNN、RNN、Transformer 只是把“加权求和”这一步，换成了更复杂的运算：
> - 卷积运算（CNN）
> - 循环更新（RNN）
> - 注意力加权（Transformer）

**你会反向传播，就等于学会了所有网络的训练原理。**


## 四、神经网络是如何训练的？

### 4.1 前向传播（Forward）
```



原始特征（如：像素值、词向量）
│
↓ 进入第一层
│
每个神经元有自己的参数（权重w + 偏置b）
│
↓ 每个神经元计算：输出 = 激活函数(∑(w × 输入) + b)
│
第一层所有神经元的输出 → 成为新的“特征组合”
│
↓ 传入第二层
│
...
│
↓
最终输出 → 预测结果

text

```
### 4.2 你的原话总结（非常准确）

> **“把原始特征全丢进去，神经元们因为起点不同、梯度不同，各自走向不同方向，自动学会哪些特征重要、怎么组合，最终形成一堆参数，这就是训练出来的模型。”**

### 4.3 关键点梳理

| 你的原话 | 是否正确 | 补充说明 |
|----------|:--------:|----------|
| “每个神经元的初始参数不一样，输出的结果不一样” | ✅ | 随机初始化保证各神经元走向不同 |
| “对损失的影响不一样，梯度下降的角度不一样” | ✅ | 梯度不同 → 参数更新方向不同 |
| “有些特征的权重被趋近于0了” | ✅ | 不重要的特征权重会变为接近0 |
| “第一层的所有神经元变成了新的特征组合” | ✅ | 这就是“深度”的含义——层层递进 |
| “第一次初始化的参数太远了，所以要训练很多轮” | ✅ | 多轮次就是重复走同一条路，直到到达最低点 |
| “后面一轮接着用前一轮的参数” | ✅ | 不是从头开始，是接着上一轮继续优化 |
| “每个神经元有自己的偏置” | ✅ | 偏置调整每个神经元的“基础兴奋度” |
| “所有参数的值同时调整” | ✅ | 一次反向传播，全部参数一起更新 |
| “参数非常多，不是简单的 Wx+b 那种几个” | ✅ | 你的模型可能有几万到几百万个参数 |


## 五、超参数

### 5.1 传统机器学习的超参数

| 算法 | 超参数 |
|------|--------|
| KNN | `K`、`metric` |
| 线性回归 | `alpha`（学习率）、`max_iter` |
| 逻辑回归 | `C`、`penalty`、`solver`、`max_iter` |
| 决策树 | `max_depth`、`min_samples_split`、`criterion` |
| K-Means | `K`、`max_iter`、`n_init` |

### 5.2 深度学习的超参数

#### 训练相关（所有网络通用）

| 超参数 | 说明 |
|--------|------|
| **学习率 lr** | 步长，最重要的超参数 |
| **批量大小 batch_size** | 每批样本数 |
| **迭代次数 epochs** | 训练轮数 |
| **优化器** | SGD / Adam / RMSprop |
| **学习率衰减策略** | StepLR / ExponentialLR |
| **正则化系数 weight decay** | L2 正则化 |
| **Dropout 概率** | 随机失活比例 |
| **梯度裁剪阈值** | 防梯度爆炸 |

#### 网络结构相关

| 超参数 | 说明 |
|--------|------|
| 层数 | 隐藏层数量 |
| 每层神经元个数 | 隐藏层宽度 |
| 激活函数 | ReLU / Tanh / Sigmoid |
| 卷积核大小（CNN） | 3×3 / 5×5 |
| 卷积核数量（CNN） | 16 / 32 / 64 |
| 步长 stride | 卷积步长 |
| 池化窗口大小 | MaxPool / AvgPool |
| RNN 隐藏状态维度 | `hidden_size` |
| Transformer 头数 | `num_heads` |

### 5.3 损失函数不是超参数

> 损失函数是“任务目标的定义”：
> - 分类任务 → 交叉熵（CrossEntropyLoss）
> - 回归任务 → MSE（MSELoss）
>
> 它由**任务类型**决定，不是需要人工调优的超参数。

> **总**：深度学习是机器学习的一个分支，以人工神经网络为核心结构，实现自动提取数据特征的算法。

> - **与传统机器学习的区别**：最大的区别是特征工程——传统ML需要人工设计特征，深度学习通过神经网络自动完成特征提取与组合。代价是需要更多数据、更高算力、更低可解释性。

> - **超参数**：分为训练相关（学习率、batch_size、epochs）和结构相关（层数、神经元数、卷积核大小等）。

## 四、神经网络是怎么训练的？

### 4.1 前向传播（一句话）

> 原始特征进入第一层 → 每个神经元有自己的参数（权重+偏置）→ 计算结果成为新的“特征组合” → 传入下一层 → ... → 最终输出预测结果。

### 4.2 你只需要记住这三点

| 关键点 | 说明 |
|--------|------|
| **参数初始化不同** | 每个神经元的初始参数不一样，导致它们走向不同方向 |
| **梯度更新** | 所有参数同时调整，不重要的特征权重趋近于0 |
| **层层递进** | 每一层的输出变成下一层的“新特征”，这就是“深度”的含义 |

### 4.3 核心机制
```



第一步：随机初始化所有参数（权重 + 偏置）
↓
第二步：前向传播 → 计算预测值
↓
第三步：计算损失（预测值 vs 真实值）
↓
第四步：反向传播 → 计算每个参数对损失的影响（梯度）
↓
第五步：梯度下降 → 所有参数同时更新
↓
重复第二步到第五步 → 直到损失足够小

text

```
