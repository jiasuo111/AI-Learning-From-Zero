# 深度学习训练模型全流程

> 教你从头到尾跑通一个深度学习模型，把前向传播、反向传播、梯度更新这些概念串起来。


## 一、整体流程概览

导包 → 设置超参数 → 准备数据 → 创建数据加载器 → 搭建模型 → 训练 → 评估

| 步骤          | 对应函数              | 输出                        |
| ------------- | --------------------- | --------------------------- |
| 1. 导包       | —                     | 导入所有需要的库            |
| 2. 超参数     | —                     | 方便后期调参                |
| 3. 准备数据   | `step1_get_data()`    | 训练集 + 测试集（标准化后） |
| 4. 数据加载器 | `step2_data_loader()` | 批次化的训练/测试加载器     |
| 5. 搭建模型   | `Step3PrepModel`      | 神经网络模型                |
| 6. 训练模型   | `step4_train()`       | 保存好的模型参数文件        |
| 7. 评估模型   | `step5_eval()`        | 准确率（或其他指标）        |

import pandas as pd
import numpy as np

from sklearn.model_selection import train_test_split

## 三、第2步：设置超参数

**目的**：把重要的参数统一放在开头，方便后面调整。

python

```
# 数据路径
data_path = 'phone_data.csv'

# 模型存储路径
model_path = 'my_model.pth'

# 批次大小：每次喂给模型多少条数据
batch_size = 16

# 训练轮次：整个数据集完整跑多少遍
epochs = 50

# 学习率：参数更新的步长
lr = 0.01
```



> 💡 **参数说明**：
>
> - `batch_size`：每次取多少样本去算梯度 → 数据量大时必用，否则显存爆了
> - `epochs`：跑完整数据集的次数，不是更新参数的次数，是完整走完所有批次的次数
> - `lr`：步长，大了容易跳过最优解，小了收敛慢

## 四、第3步：准备数据

**目的**：拿到 4 个数据：`x_train, x_test, y_train, y_test`，并且完成标准化。

python

```
def step1_get_data(data_path):
    """
    从CSV文件读取数据，划分训练集和测试集，并标准化
    返回：x_train, x_test, y_train, y_test
    """
    # 1. 读取数据
    data = pd.read_csv(data_path)
    
    # 2. 分离特征 x 和标签 y
    x = data.iloc[:, :-1]    # 最后一列是标签，前面都是特征
    y = data.iloc[:, -1]     # 最后一列是标签
    
    # 3. 划分训练集和测试集（80% 训练，20% 测试）
    x_train, x_test, y_train, y_test = train_test_split(
        x, y, test_size=0.2, random_state=6666
    )
    
    # 4. 标准化（让数据均值为0，方差为1）
    #    为什么标准化？防止某个特征数值太大，主导了梯度更新
    ss = StandardScaler()
    x_train = ss.fit_transform(x_train)   # 训练集：fit + transform
    x_test = ss.transform(x_test)         # 测试集：只 transform，用训练集的参数
    
    return x_train, x_test, y_train, y_test
```



**调用**：

python

```
x_train, x_test, y_train, y_test = step1_get_data(data_path)
```



## 五、第4步：创建数据加载器

**目的**：把数据变成 PyTorch 能吃的格式，并且分批次打包。

python

```
def step2_data_loader(batch_size, x_train, x_test, y_train, y_test):
    """
    将数据封装为 TensorDataset，然后创建 DataLoader
    返回：train_dataloader, test_dataloader
    """
    # 1. numpy → Tensor（必须转成 Tensor 才能进 PyTorch）
    #    特征要 float32，标签要 long（因为分类任务）
    train_dataset = TensorDataset(
        torch.from_numpy(x_train).float(),
        torch.from_numpy(y_train.values).long()
    )
    test_dataset = TensorDataset(
        torch.from_numpy(x_test).float(),
        torch.from_numpy(y_test.values).long()
    )
    
    # 2. 创建 DataLoader（负责分批次、打乱顺序）
    train_dataloader = DataLoader(
        train_dataset, 
        batch_size=batch_size, 
        shuffle=True      # 训练集要打乱，避免模型记住顺序
    )
    test_dataloader = DataLoader(
        test_dataset, 
        batch_size=batch_size, 
        shuffle=False     # 测试集不需要打乱
    )
    
    return train_dataloader, test_dataloader
```



**调用**：

python

```
train_dataloader, test_dataloader = step2_data_loader(
    batch_size, x_train, x_test, y_train, y_test
)
```



## 六、第5步：搭建模型

**目的**：定义一个神经网络类，包含 **init** 和 forward 两个核心方法。

python

```
class Step3PrepModel(nn.Module):
    """
    自定义神经网络模型
    继承 nn.Module，重写 __init__ 和 forward
    """
    def __init__(self, input_sum, output_sum):
        """
        input_sum：输入特征的数量（x_train 的列数）
        output_sum：输出类别的数量（y_train 中不同值的个数）
        """
        super().__init__()
        
        # 定义每一层（全连接层）
        # 输入 → 隐藏层1（128个神经元）
        self.fc1 = nn.Linear(input_sum, 128)
        # 隐藏层1 → 隐藏层2（256个神经元）
        self.fc2 = nn.Linear(128, 256)
        # 隐藏层2 → 输出层（output_sum 个神经元）
        self.out = nn.Linear(256, output_sum)
    
    def forward(self, x):
        """
        前向传播：数据从输入层流向输出层
        """
        # 每层：加权求和 + ReLU 激活
        x = torch.relu(self.fc1(x))
        x = torch.relu(self.fc2(x))
        # 输出层：只做加权求和，不激活（交给 CrossEntropyLoss 处理）
        x = self.out(x)
        return x
```



**调用**：

python

```
# input_sum = 特征个数，output_sum = 分类个数
input_sum = len(x_train[0])           # 有多少列特征
output_sum = len(y_train.unique())    # 有多少个分类

model = Step3PrepModel(input_sum, output_sum)
```



> 💡 **关于输出层的设计**：
>
> - **多分类**：输出层神经元个数 = 类别数，用 `CrossEntropyLoss`（自带 Softmax）
> - **二分类**：输出层 1 个神经元，用 `Sigmoid` + `BCELoss`
> - **回归**：输出层 1 个神经元，用 `MSELoss`

## 七、第6步：训练模型

**目的**：让模型在训练集上不断学习，更新参数，保存最好的模型。

python

```
def step4_train(model, train_dataloader, model_path, epochs, lr):
    """
    训练模型
    """
    # 1. 准备损失函数（分类任务用交叉熵）
    loss_fn = nn.CrossEntropyLoss()
    
    # 2. 准备优化器（Adam 是深度学习的首选优化器）
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    
    # 3. 开始训练
    for epoch in range(1, epochs + 1):
        start_time = time.time()
        total_loss = 0
        
        # 切换为训练模式（Dropout、BN 生效）
        model.train()
        
        # 遍历每一个批次
        for batch_x, batch_y in train_dataloader:
            # ----- 5 大核心步骤（⭐重点）-----
            
            # ① 前向传播：算预测值
            pred_y = model(batch_x)
            
            # ② 算损失：预测值 vs 真实值
            loss = loss_fn(pred_y, batch_y)
            total_loss += loss
            
            # ③ 梯度清零（避免梯度累加）
            optimizer.zero_grad()
            
            # ④ 反向传播（计算梯度）
            loss.backward()
            
            # ⑤ 优化器更新参数（梯度下降）
            optimizer.step()
        
        # 打印日志
        avg_loss = total_loss / len(train_dataloader)
        elapsed = time.time() - start_time
        print(f'Epoch {epoch}/{epochs} | 平均损失: {avg_loss:.4f} | 耗时: {elapsed:.2f}s')
    
    # 4. 保存模型参数
    torch.save(model.state_dict(), model_path)
    print(f'模型已保存到: {model_path}')
```



**调用**：

python

```
step4_train(model, train_dataloader, model_path, epochs, lr)
```



## 八、第7步：评估模型

**目的**：在测试集上评估模型的准确率。

python

```
def step5_eval(test_dataloader, model_path, input_sum, output_sum):
    """
    评估模型在测试集上的准确率
    """
    # 1. 创建一个相同结构的模型，加载训练好的参数
    model = Step3PrepModel(input_sum, output_sum)
    model.load_state_dict(torch.load(model_path))
    
    # 2. 切换为评估模式（Dropout 失效，BN 用全局统计）
    model.eval()
    
    correct = 0
    total = 0
    
    # 3. 禁用梯度计算（加速 + 省显存）
    with torch.no_grad():
        for batch_x, batch_y in test_dataloader:
            # 前向传播得到预测分数
            logits = model(batch_x)
            # 取分数最高的类别作为预测结果
            pred_y = logits.argmax(dim=-1)
            
            # 统计正确的个数
            correct += (pred_y == batch_y).sum().item()
            total += batch_y.size(0)
    
    # 4. 计算准确率
    accuracy = correct / total
    print(f'测试集准确率: {accuracy:.4f}')
    
    return accuracy
```



**调用**：

python

```
step5_eval(test_dataloader, model_path, input_sum, output_sum)
```

## 十一、常见问题

### Q1：为什么要做标准化？

> 不同特征的数值范围可能差很大（比如年龄 0-100，收入 0-100000），梯度下降时量级大的特征会主导更新方向。标准化后所有特征都在同一量级，模型收敛更快更稳定。

### Q2：batch_size 怎么选？

> - 太大 → 内存/显存不够，梯度更新方向更准但慢
> - 太小 → 梯度噪声大，收敛不稳定
> - 常用值：16、32、64、128（视显卡内存而定）

### Q3：epochs 怎么选？

> - 训练集损失不再下降 → 停止
> - 验证集损失开始上升 → 早停（过拟合信号）
> - 一般先设个 100，观察曲线再调整

### Q4：训练模式和评估模式有什么区别？

| 模式 | API             | Dropout | BatchNorm      |
| :--- | :-------------- | :------ | :------------- |
| 训练 | `model.train()` | ✅ 生效  | 用当前批次统计 |
| 评估 | `model.eval()`  | ❌ 失效  | 用全局统计     |

### Q5：为什么要分批次训练？

> 1. 数据太大，一次性加载不进内存/显存
> 2. 批次间的噪声有助于跳出局部最优
> 3. 能看到训练过程中的损失变化
