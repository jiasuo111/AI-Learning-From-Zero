# 06_RNN

# 循环神经网络 RNN

> RNN 是专门处理序列数据的神经网络，比如文本、语音、时间序列。它通过隐藏状态在时间步之间传递信息，让网络能够“记住”之前看到的内容。


## 一、课程引入

### 1.1 先看一个问题

全连接网络和 CNN 都有一个共同点：**输入之间是独立的**。

- 一张图片 → 一个预测结果
- 一个样本 → 一个输出

但很多数据是**序列**：

“我喜欢吃____”

text

```
要预测空格里填什么，不能只看“吃”这个字，得看前面的“我喜欢”。也就是说：**上下文有关**。

> RNN 就是为处理这类序列数据而生的。

### 1.2 RNN 是什么？

**一句话定义**：RNN 是一种专门处理序列数据的神经网络，通过**隐藏状态（hidden state）** 在时间步之间传递信息，使网络能够“记住”之前看到的内容。

**核心特点**：所有时间步**共享同一组参数**。


## 二、RNN 的核心机制

### 2.1 隐藏状态的计算

> hₜ = tanh(W_ih · xₜ + W_hh · hₜ₋₁ + b)

| 符号 | 含义 |
|------|------|
| xₜ | 当前时间步的输入（如当前词） |
| hₜ₋₁ | 上一步的隐藏状态 |
| hₜ | 当前步的隐藏状态 |
| W_ih, W_hh, b | 可学习参数（**所有时间步共享**） |

### 2.2 图解 RNN
```



y₁ y₂ y₃ y₄
↑ ↑ ↑ ↑
│ │ │ │
┌─────┴─────┐ ┌─────┴─────┐ ┌─────┴─────┐ ┌─────┴─────┐
│ RNN Cell │ │ RNN Cell │ │ RNN Cell │ │ RNN Cell │
│ h₀──→h₁ │ │ h₁──→h₂ │ │ h₂──→h₃ │ │ h₃──→h₄ │
└─────┬─────┘ └─────┬─────┘ └─────┬─────┘ └─────┬─────┘
↑ ↑ ↑ ↑
│ │ │ │
x₁ x₂ x₃ x₄

text

```
**核心公式**：
> hₜ = tanh(W_ih · xₜ + W_hh · hₜ₋₁ + b)

**关键理解**：
- 当前步的输出 yₜ 由当前步的隐藏状态 hₜ 决定
- 隐藏状态 hₜ 包含了**当前输入 + 上一步的记忆**
- 预测值和真实值的关系：训练时真实词更新 h，预测值只用来算损失


## 三、训练 vs 推理

### 3.1 训练阶段（有真实标签）
```



输入：真实词 x₁, x₂, x₃, ...
↓
逐时间步计算 hₜ（用真实词 xₜ）
↓
用 hₜ 预测下一个词 ŷₜ
↓
计算损失（预测 vs 真实）
↓
反向传播更新参数

关键：用真实词更新 h，预测值只用来算损失

text

```
### 3.2 推理/生成阶段（无真实标签）
```



输入：起始词（或前缀）
↓
用自己的预测词作为下一步输入
↓
hₜ = f(hₜ₋₁, 自己预测的词)
↓
继续预测下一个词
↓
重复直到结束

关键：用自己的预测值更新 h，没有真实词可用

text

```
### 3.3 两种推理模式

| 模式 | 输入 | 输出 | 典型例子 |
|------|------|------|----------|
| **自回归生成** | 一个起始词 | 逐步生成后续词 | 文本续写、写诗 |
| **一对一映射** | 完整序列（逐词） | 每个词对应的输出 | 词性标注、命名实体识别 |

> 💡 **RNN 输入长度 = 输出长度**（一对一，或一对零）。要输出不同长度的序列（如翻译），必须用 Seq2Seq 架构。


## 四、参数共享

### 4.1 共享什么？

| 参数 | 说明 | 是否共享 |
|------|------|----------|
| W_ih | 输入到隐藏的权重 | ✅ 所有时间步共享 |
| W_hh | 隐藏到隐藏的权重 | ✅ 所有时间步共享 |
| b | 偏置 | ✅ 所有时间步共享 |

### 4.2 共享的含义

> 无论当前是第 1 个词还是第 100 个词，无论处理的是句子 A 还是句子 B，用的都是同一组参数。

**假设**：词与词之间的动态规律是相同的，不管出现在什么位置。

### 4.3 变长序列的支持

> RNN 天然支持变长序列，因为它按时间步逐个处理输入，参数与序列长度无关。

但 PyTorch 要求一个 batch 里的张量形状相同，所以工程上需要用 **padding** + `pack_padded_sequence` 来处理。

> 这是工程实现的需要，不是 RNN 的设计缺陷。


## 五、梯度消失与梯度爆炸

### 5.1 数学原因

在反向传播中，梯度要从最后一步往前传：
```



δₜ₋₁ = δₜ · (W_hhᵀ · diag(tanh'(hₜ)))

text

```
**关键问题**：往回传一步就要乘一次 W_hh。如果序列长度是 100，就要乘 100 次 W_hh。

### 5.2 消失 vs 爆炸

| 情况 | 条件 | 结果 |
|------|------|------|
| **梯度消失** | W_hh 的谱半径 < 1 | 早期词梯度 ≈ 0 → 学不到开头信息（遗忘） |
| **梯度爆炸** | W_hh 的谱半径 > 1 | 梯度指数级增长 → 参数变 NaN → 训练崩溃 |

### 5.3 为什么参数共享会导致梯度消失/爆炸？

> 如果不共享参数，不同时间步的 W_hh⁽ᵗ⁾ 可以有大有小、正负交替，梯度回传时不会单调地同一方向缩放。但 RNN 共享参数，同一个 W_hh 在所有时间步重复使用，只能一直变大或一直变小。”

> 梯度消失时，靠近输入端的权重几乎接收不到有效的梯度信号，因此无法更新。模型就“注意不到”早期词的重要性，表现为遗忘。

> 梯度爆炸的直接结果是训练失败：损失变成 NaN，参数变成 NaN，模型彻底报废。


## 六、RNN 做续写
```



把前缀逐步读入 → 最后隐藏状态 hₙ 包含整句信息
↓
从 hₙ 开始自回归生成后续内容
↓
每次用自己的预测词更新 h

问题：长句子时开头信息容易丢失（梯度消失）→ 效果不如 Transformer

text

```
## 七、优缺点

### 优点

| 优点 | 说明 |
|------|------|
| ✅ 天然支持变长序列 | 按时间步逐个处理 |
| ✅ 参数量小 | 适合资源受限场景 |
| ✅ 推理复杂度 O(n) | 比 Transformer 的 O(n²) 更快 |

### 缺点

| 缺点 | 说明 |
|------|------|
| ❌ 长距离依赖差 | 梯度消失导致记不住开头 |
| ❌ 无法并行 | 必须逐时间步计算，训练慢 |
| ❌ 记忆容量有限 | 隐藏状态 hₜ 维度有限 |

> 💡 **总结**：RNN 的核心是隐藏状态 + 参数共享，适合短序列。长序列请用 LSTM 或 Transformer。


## 八、PyTorch API

​```python
import torch
import torch.nn as nn

# RNN 层
# input_size: 输入特征维度
# hidden_size: 隐藏状态维度
# num_layers: 隐藏层数
rnn = nn.RNN(input_size=8, hidden_size=16, num_layers=3, batch_first=False)

# 输入: (seq_len, batch_size, input_size)
x = torch.randn(5, 2, 8)   # seq_len=5, batch=2, input=8

# 初始隐藏状态: (num_layers, batch_size, hidden_size)
h0 = torch.zeros(3, 2, 16)

# 输出: (seq_len, batch_size, hidden_size)
out, hn = rnn(x, h0)

print(out.shape)  # torch.Size([5, 2, 16])
print(hn.shape)   # torch.Size([3, 2, 16])
```



### 常用参数

| 参数                  | 说明                                      |
| :-------------------- | :---------------------------------------- |
| `batch_first=True`    | 输入形状改为 (batch, seq_len, input_size) |
| `bidirectional=True`  | 双向 RNN                                  |
| `nonlinearity='relu'` | 用 ReLU 代替 tanh                         |

## 九、面试回答模板（总分总）

> **总**：RNN 是专门处理序列数据的神经网络，通过隐藏状态在时间步之间传递信息，所有时间步共享同一组参数。

> **分**：
>
> 1. **核心机制**：隐藏状态 hₜ = tanh(W_ih·xₜ + W_hh·hₜ₋₁ + b)，既包含当前输入，也包含历史信息。预测时根据 hₜ 输出。
> 2. **训练与推理的区别**：训练时用真实词更新 h，预测值只算损失；推理时用自己的预测词更新 h，没有真实词。
> 3. **参数共享**：RNN 在所有时间步共享 W_ih、W_hh，这是它能处理变长序列的原因，但也导致了梯度消失/爆炸。
> 4. **梯度问题**：反向传播时要反复乘以同一个 W_hh，导致梯度指数级消失或爆炸。梯度消失会让模型“忘记”句子开头的信息。

> **总**：RNN 的核心是隐藏状态 + 参数共享，适合短序列。长序列请用 LSTM 或 Transformer。

## 十、一句话总结

> **RNN 用同一个 W 反复乘，所以能记住（短序列）也会忘（长序列）。**
