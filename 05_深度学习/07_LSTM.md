# 07_LSTM

# 长短期记忆网络 LSTM

> LSTM 是 RNN 的改进版本，专门为了解决 RNN 记不住长距离信息的问题而设计。


## 一、课程引入

### 1.1 RNN 的问题：记不住开头

RNN 通过隐藏状态 h 传递信息，但反向传播时梯度要反复乘以同一个 W_hh，导致：

- **梯度消失** → 前面的信息传不到后面 → 记不住开头
- **梯度爆炸** → 训练崩溃

> RNN 就像一个记忆力很差的人，刚说完的话还记得，但聊了十分钟后开头说了啥全忘了。

### 1.2 LSTM 的答案

> LSTM = RNN + 门控记忆单元，能记住几百步前的内容。

**一句话定义**：LSTM（Long Short-Term Memory，长短期记忆网络）通过引入**门控机制**和**细胞状态**，让网络能够有选择地记住或遗忘信息。


## 二、LSTM 的核心思想

### 2.1 RNN vs LSTM

| 对比     | RNN                  | LSTM                            |
| -------- | -------------------- | ------------------------------- |
| 记忆结构 | 只有隐藏状态 h       | 隐藏状态 h + **细胞状态 C**     |
| 信息传递 | 每步都经过 tanh 压缩 | 细胞状态 C 可以**几乎无损**传递 |
| 长期记忆 | ❌ 记不住             | ✅ 能记住                        |
| 梯度问题 | 消失/爆炸严重        | 大幅缓解                        |

> 💡 **核心洞察**：LSTM 多了一条「高速公路」C（细胞状态），信息在上面几乎无损地传递，不会被反复压缩。

### 2.2 还是用 h 做预测

> 你理解得对：LSTM 仍然用隐藏状态 h 做预测，但新增了细胞状态 C 作为长期记忆通道。

| 状态               | 作用                 | 传递方式                   |
| ------------------ | -------------------- | -------------------------- |
| **hₜ（隐藏状态）** | 当前输出，做预测用   | 每步都经过门控，有信息损失 |
| **Cₜ（细胞状态）** | 长期记忆，存重要信息 | 通过**加法**传递，几乎无损 |


## 三、三个门控机制

### 3.1 核心思路流程

> 你的理解是对的，用大白话说就是：

上一轮的 C（长期记忆）
│
├──→ 遗忘门：决定“忘掉多少旧记忆”
│
当前输入 xₜ + 上一步 hₜ₋₁
│
├──→ 输入门：决定“记住多少新信息”
│
└──→ 两者融合 → 当前步 Cₜ（更新后的长期记忆）
│
├──→ 输出门：决定“从记忆中提取多少作为当前输出”
│
└──→ 当前步 hₜ（用于预测）

text

```
### 3.2 三个门的具体作用

| 门控 | 作用 | 决策内容 |
|------|------|----------|
| **遗忘门（Forget Gate）** | 从旧记忆 Cₜ₋₁ 中删掉不重要的 | 0 = 全忘，1 = 全留 |
| **输入门（Input Gate）** | 从当前输入中选出值得记住的 | 选多少新信息写入 Cₜ |
| **输出门（Output Gate）** | 从 Cₜ 中提取多少作为当前输出 hₜ | 决定当前步对外展示什么 |

### 3.3 你的理解（非常准确）

> “遗忘门是把上一轮的 C 传入一部分到新的 C。输入门是把上一步的 h 和当前步的 x 传入一部分给 C。输出门是把 C 传入当前步的 h。当前的 h 仅仅由当前的 C 决定。”

✅ **完全正确！** 这就是 LSTM 的核心逻辑。


## 四、为什么 LSTM 能缓解梯度消失？

### 4.1 关键原因：加法传递

RNN 的隐藏状态更新是**乘法**：
> hₜ = tanh(W·hₜ₋₁ + ...) → 梯度反复乘以 W → 消失/爆炸

LSTM 的细胞状态更新是**加法**：
> Cₜ = fₜ * Cₜ₋₁ + iₜ * C̃ₜ
> ↑ 加法！梯度可以无损传回去

### 4.2 梯度高速公路
```



C₀ ──→ C₁ ──→ C₂ ──→ C₃ ──→ C₄
↑ ↑ ↑ ↑
加法 加法 加法 加法

text

```
> 梯度沿着 C 这条线传回去时，只经过加法，不会被反复乘以同一个矩阵而指数级衰减。

### 4.3 一个重要的澄清

> LSTM 并没有完全消除梯度消失。它通过细胞状态 Cₜ 的加法更新，提供了另一条梯度传播通道。即使 hₜ 的梯度消失了，Cₜ 仍然可能继续学习。

> 但 hₜ 的梯度爆炸**仍然存在**，需要通过**梯度裁剪**来防止训练崩溃。


## 五、LSTM vs RNN 效果对比

### 5.1 为什么 LSTM 效果好很多？

不是因为参数量更大，而是因为**训练效果更好**：

| 问题 | RNN | LSTM |
|------|-----|------|
| 早期参数能否收到梯度？ | ❌ 梯度消失 → 收不到 → 相当于废了 | ✅ 通过 C 通道能收到 → 能学习 |
| 长距离信息能记住吗？ | ❌ 记不住 | ✅ 能记住 |
| 训练稳定性 | 差 | 好（配合梯度裁剪） |

> LSTM 通过细胞状态让梯度可以无损远传，从而真正用满了这些参数。


## 六、API 使用

### 6.1 基本用法

​```python
import torch
import torch.nn as nn

# 定义 LSTM
lstm = nn.LSTM(
    input_size=10,       # 输入特征维度
    hidden_size=20,      # 隐藏状态 h 的维度（也是 C 的维度）
    num_layers=2,        # 层数
    batch_first=True,    # 输入形状：(batch, seq, feature)
    bidirectional=False  # 是否双向
)

# 输入：(batch=4, seq_len=6, input_size=10)
x = torch.randn(4, 6, 10)

# 初始化状态
h0 = torch.zeros(2, 4, 20)   # (num_layers, batch, hidden)
c0 = torch.zeros(2, 4, 20)   # 形状同 h0

# 前向传播
output, (h_n, c_n) = lstm(x, (h0, c0))

print(output.shape)  # torch.Size([4, 6, 20])
print(h_n.shape)     # torch.Size([2, 4, 20])
print(c_n.shape)     # torch.Size([2, 4, 20])
```



### 6.2 双向 LSTM

python

```
lstm = nn.LSTM(10, 20, num_layers=2, bidirectional=True)

# 双向时，输出维度是 hidden_size * 2
x = torch.randn(4, 6, 10)
output, _ = lstm(x)
print(output.shape)  # torch.Size([4, 6, 40])
```

## 七、优缺点

### 优点

| 优点                        | 说明                   |
| :-------------------------- | :--------------------- |
| ✅ 解决了 RNN 的长期依赖问题 | 能记住几百步前的内容   |
| ✅ 梯度消失大幅缓解          | 通过细胞状态的加法传递 |
| ✅ 在各种序列任务中表现稳定  | 文本、语音、时间序列   |

### 缺点

| 缺点                   | 说明                         |
| :--------------------- | :--------------------------- |
| ❌ 无法完全避免梯度消失 | 超长序列仍会忘               |
| ❌ 无法并行计算         | 必须逐时间步执行             |
| ❌ 被 Transformer 超越  | 长文本生成已转向 Transformer |

## 八、LSTM vs GRU

| 对比       | LSTM                           | GRU                    |
| :--------- | :----------------------------- | :--------------------- |
| 门控数量   | 3 个（遗忘门、输入门、输出门） | 2 个（更新门、重置门） |
| 细胞状态 C | ✅ 有单独的状态                 | ❌ 没有，只用 h         |
| 参数量     | 更大                           | 更少                   |
| 训练速度   | 较慢                           | 较快                   |
| 效果       | 理论上更好                     | 效果接近               |
| 适用场景   | 长序列、复杂任务               | 通用任务、资源受限     |

> 💡 **GRU 是 LSTM 的简化版**，效果接近但训练更快，适合大多数通用任务。

## 九、面试回答模板（总分总）

> **总**：LSTM 是 RNN 的改进版本，通过引入门控机制和细胞状态，解决了 RNN 的长期依赖问题，能记住几百步前的内容。

> **分**：
>
> 1. **核心机制**：LSTM 有三个门——遗忘门决定丢掉什么旧信息，输入门决定存入什么新信息，输出门决定输出什么。通过细胞状态 C 让信息几乎无损地传递。
> 2. **为什么能缓解梯度消失**：细胞状态 Cₜ 的更新是通过**加法**而不是乘法，梯度可以沿着 C 直接传回去，不会被反复乘以同一矩阵而指数级衰减。
> 3. **与 RNN 的区别**：RNN 只有一个 h，信息被反复压进同一个容器；LSTM 多了一条 C 专门存长期记忆，h 主要负责输出。

> **总**：LSTM 是处理长序列任务的主力模型，但在大模型时代，长文本生成已被 Transformer 取代，短序列和时序预测仍有使用空间。

## 十、总结

### 一句话总结

> **LSTM = RNN + 门控记忆单元，用 C 记住长距离信息，用 h 做预测。**
