# 09_Seq2Seq

# Seq2Seq 序列到序列模型

> Seq2Seq 是机器翻译、文本摘要、对话系统的核心架构，也是大模型的基础思想之一。


## 一、课程引入

### 1.1 RNN 的局限

前面学的 RNN、LSTM、GRU 都有一个共同点：

> **输入长度 = 输出长度**

输入 5 个词，输出 5 个对应的结果。

但很多任务不是这样的：

| 任务                                         | 输入长度 | 输出长度      |
| -------------------------------------------- | -------- | ------------- |
| 机器翻译 "我爱你" → "I love you"             | 3        | 3（碰巧一样） |
| 文本摘要（长文章 → 短摘要）                  | 500      | 50            |
| 对话系统 "今天天气怎么样？" → "今天晴，25°C" | 7        | 6             |

> 输入和输出的长度**不一样**，而且没有一一对应关系。

**怎么解决？**

> Seq2Seq 就是答案。


## 二、Seq2Seq 是什么？

**一句话定义**：Seq2Seq（Sequence-to-Sequence）是一种**编码器-解码器架构**，用于把一个变长序列映射到另一个变长序列，两者长度可以不同。

**经典场景**：

| 任务     | 输入     | 输出       |
| -------- | -------- | ---------- |
| 机器翻译 | 中文句子 | 英文句子   |
| 文本摘要 | 长文章   | 短摘要     |
| 对话系统 | 用户问题 | 机器人回答 |


## 三、核心架构

### 3.1 两大组件

┌─────────────────────────────────────────────────────────────┐
│ Seq2Seq 架构 │
├─────────────────────────────────────────────────────────────┤
│ │
│ 编码器（Encoder） 解码器（Decoder） │
│ ↓ ↓ │
│ 读入整个输入序列 逐步生成输出序列 │
│ ↓ ↓ │
│ 输出最后一个隐藏状态 每一步依赖上一步的输出 │
│ ↓ ↓ │
│ 传给解码器作为初始状态 直到生成结束符 <END> │
│ │
└─────────────────────────────────────────────────────────────┘

text

```
### 3.2 图解流程
```



输入: 我 爱 你
↓ ↓ ↓
[编码器 RNN]
↓
最后一个 h₃（语义向量）
↓
[解码器 RNN]
↓ ↓ ↓
输出: I love you <END>

text

```
### 3.3 编码器（Encoder）

> 把输入序列压缩成一个**语义向量**（Context Vector）
```



x₁ → h₁
x₂ → h₂
x₃ → h₃ ← 最后一个隐藏状态 = 语义向量

text

```
**实现方式**：RNN / LSTM / GRU（任选，GRU 最常用）

**编码器做的事**：把“我 爱 你”这三个词的信息，全部压缩进最后一个隐藏状态 h₃。

### 3.4 解码器（Decoder）

> 从语义向量开始，**逐步生成**输出序列
```



h₁' → 预测 y₁（I）
h₃（语义向量）→ h₂' → 预测 y₂（love）
h₃' → 预测 y₃（you）
h₄' → 预测 y₄（<END>）

text

```
**解码器的输入输出**：

| 要素 | 说明 |
|------|------|
| 初始状态 | 编码器的最后一个隐藏状态 h₃ |
| 每一步输入 | 上一步的输出词（训练时用真实词，推理时用预测词） |
| 每一步输出 | 当前时间步的预测词 |
| 停止条件 | 生成 `<END>` 或达到最大长度 |


## 四、训练 vs 推理

### 4.1 训练阶段（Teacher Forcing）
```



输入: 我 爱 你
↓ ↓ ↓
[编码器 RNN]
↓
最后一个 h₃
↓
[解码器 RNN]
↓ ↓ ↓
真实词: I love you ← 作为每一步的输入

text

```
> 💡 **Teacher Forcing**：训练时，不管模型上一步预测什么，都**用真实词**作为下一步的输入。这样收敛更快、更稳定。

### 4.2 推理阶段（自回归生成）
```



输入: 我 爱 你
↓ ↓ ↓
[编码器 RNN]
↓
最后一个 h₃
↓
[解码器 RNN]
↓ ↓ ↓
预测: I love you ← 用自己的预测作为下一步输入

text

```
> 💡 **自回归生成**：推理时，模型用**自己预测的词**作为下一步的输入，直到生成 `<END>`。

### 4.3 你的理解（完全正确）

> “解码器是拿到了一个 h，然后输出 y，然后 y 当 x，把 x 和上一个 h 去更新当前 h。然后每一步就和 RNN 一样了，预测 → 自回归 → 更新 h → 预测。”

✅ **完全正确！** 解码器本质上就是一个 RNN 的自回归生成过程。


## 五、Seq2Seq 的核心问题

### 5.1 记忆力问题

编码器把**整个句子**压缩成一个**固定长度**的向量 h₃。

- 短句子（3 个词）→ 没问题
- 长句子（50 个词）→ 开头信息被挤没了

> 就像让你把整本《三体》压缩成一句话，再说给别人听，别人肯定记不住细节。

### 5.2 解决方案：注意力机制（Attention）

> 解码器生成第 t 个词时，可以**直接查看编码器的所有隐藏状态**，而不是只靠最后一个 h。
```



解码器生成 "love" 时：
│
├── 查看 h₁（"我"）→ 匹配度 0.1
├── 查看 h₂（"爱"）→ 匹配度 0.8 ← 重点看这个
└── 查看 h₃（"你"）→ 匹配度 0.1
│
↓
加权求和 → 上下文向量
│
↓
结合上下文预测 "love"

text

```
> 💡 **注意力机制的核心**：每一步都“回头看”编码器的所有输出，决定当前该重点关注哪个词。


## 六、Seq2Seq + 注意力

### 6.1 架构升级
```



输入: 我 爱 你
↓ ↓ ↓
[编码器 RNN]
↓ ↓ ↓
h₁ h₂ h₃
│ │ │
└──┬──┴──┬──┘
│ │
[注意力层] │
│ │
上下文向量 │
│ │
[解码器 RNN]
↓ ↓ ↓
输出: I love you

text

```
### 6.2 注意力机制的作用

| 作用 | 说明 |
|------|------|
| 缓解长距离遗忘 | 每一步都能直接看到输入序列的所有位置 |
| 提升翻译质量 | 生成每个词时知道该“看”输入句子的哪个部分 |
| 可解释性 | 可以画出注意力权重，看到模型在“看”什么位置 |


## 七、与 Transformer 的关系

> 你可能会问：那 Transformer 和 Seq2Seq 是什么关系？

| 对比 | Seq2Seq（经典） | Transformer |
|------|-----------------|-------------|
| 架构 | 编码器 + 解码器 | **也是编码器 + 解码器** |
| 核心组件 | RNN / LSTM | **自注意力机制** |
| 位置编码 | 天然有顺序（RNN 按时间步） | 需要额外加位置编码 |
| 并行能力 | ❌ 无法并行 | ✅ 完全并行 |

> 💡 **Transformer 保留了 Seq2Seq 的“编码器-解码器”架构思想，但用自注意力取代了 RNN。**


## 八、面试回答模板（总分总）

> **总**：Seq2Seq 是一种编码器-解码器架构，把一个变长序列映射到另一个变长序列，广泛用于机器翻译、文本摘要等任务。

> **分**：
> 1. **架构**：编码器读入整个输入，压缩成语义向量（最后一个隐藏状态）；解码器从这个向量开始，逐步生成输出序列。
> 2. **训练与推理的区别**：训练时用 Teacher Forcing（真实词作为输入），推理时用自己的预测词自回归生成。
> 3. **核心问题**：编码器把整个句子压成一个固定向量，长句子时开头信息容易丢失。注意力机制让解码器每一步直接查看编码器的所有隐藏状态，缓解了这个问题。
> 4. **与 Transformer 的关系**：Transformer 取代了 RNN，但仍然保留了“编码器-解码器”的架构思想。

> **总**：Seq2Seq 的核心是编码器压缩、解码器生成。加上注意力机制后，成为机器翻译、大模型的基础架构之一。


## 九、总结

### 一句话总结

> **Seq2Seq = 编码器把输入压成向量 + 解码器自回归生成输出。**
```
