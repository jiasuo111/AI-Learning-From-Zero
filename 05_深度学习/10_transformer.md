# 10_transformer

> Transformer 是大模型时代的基石，ChatGPT、GPT-4、LLaMA 等所有主流大模型都基于 Transformer 架构。本节带你彻底搞懂它。

## 一、课程引入

### 1.1 先看一个对比

**RNN 的问题**：

| 问题             | 说明                           |
| :--------------- | :----------------------------- |
| **长距离依赖差** | 梯度消失 → 句子开头的词记不住  |
| **无法并行**     | 必须逐时间步计算，GPU 利用率低 |
| **信息瓶颈**     | 整个句子压成一个 h_T，信息丢失 |

**Transformer 的答案**：

| 解法                           | 效果                               |
| :----------------------------- | :--------------------------------- |
| **自注意力（Self-Attention）** | 任意两词直接连接 → 距离不再是问题  |
| **全局并行**                   | 输入序列一次性全部计算             |
| **保留每个位置的特征**         | Encoder 输出每个位置的向量，不压缩 |

## 二、Transformer 是什么？

**一句话定义**：Transformer 是一种完全基于注意力机制的 Seq2Seq 架构，抛弃了 RNN 的循环结构，用**自注意力 + 前馈网络**并行处理序列。

> Transformer = Encoder + Decoder + 多头注意力 + 位置编码 + 残差连接

## 三、整体架构

text

```
输入序列（如“我爱你”）
    │
    ▼
【Encoder 栈】（6层）
    ├── 输入嵌入 + 位置编码
    ├── 多头自注意力（Multi-Head Self-Attention）
    ├── 残差连接 + LayerNorm
    ├── 前馈网络（FFN）
    └── 残差连接 + LayerNorm（重复6次）
    │
    ▼
Encoder 输出（每个位置一个特征向量）
    │
    ▼
【Decoder 栈】（6层）
    ├── 输出嵌入 + 位置编码（已生成的部分）
    ├── 带掩码的多头自注意力（Masked Self-Attention）
    ├── 残差 + LayerNorm
    ├── 交叉注意力（Cross-Attention）：Q 来自 Decoder，K/V 来自 Encoder
    ├── 残差 + LayerNorm
    ├── 前馈网络（FFN）
    └── 残差 + LayerNorm（重复6次）
    │
    ▼
输出概率（下一个词）
```



### 3.1 Encoder 和 Decoder 的对比

| 模块        | 输入         | 注意力类型                      | 是否遮挡未来       | 输出                   |
| :---------- | :----------- | :------------------------------ | :----------------- | :--------------------- |
| **Encoder** | 完整句子     | 自注意力（Self-Attention）      | ❌ 不遮挡（看全部） | 每个词融合上下文的特征 |
| **Decoder** | 已生成的部分 | 自注意力（带 Mask）+ 交叉注意力 | ✅ 遮挡未来         | 下一个词的概率分布     |

## 四、为什么要设计 Transformer？

### 4.1 RNN 做不到的事：让每个字“互相看”

> 假如每个字转成向量进去，每个字代表的内容是独立的，没有上下文信息。比如“我”在“我爱你”和“你爱我”里面意思应该不一样，但 RNN 的输入编码是一样的。

**核心思路**：设计一个机制，让每个字可以和该样本的所有字去交互，得到一个新的特征，这个特征包含了其他所有字的信息。

> 💡 这个问题就转化成了**计算权重**的问题——每个字和其他字的关系权重。

### 4.2 位置编码：解决“我”在“我爱你”和“你爱我”里的区别

> “我爱你”和“你爱我”中，“我”字融合的其他语义信息应该不一样，但如果不加位置信息，两个“我”的计算结果是一样的。

> 💡 引入**位置编码**，把位置信息加入计算过程，让不同位置的相同词产生不同的特征。

## 五、QKV 机制（核心重点）

### 5.1 什么是 QKV？

> 一段序列输入后，每个字都有自己的 Q、K、V。它们都是通过**词嵌入向量**乘以不同的权重矩阵得到的。

| 字母  | 全称          | 作用                                               |
| :---- | :------------ | :------------------------------------------------- |
| **Q** | Query（查询） | 去查询和其他文字的权重关系                         |
| **K** | Key（键）     | 等待别人的 Q 来查我                                |
| **V** | Value（值）   | 自己的内容，Q 和 K 算出权重后，从 V 里提取多少信息 |

### 5.2 QKV 的工作流程

text

```
输入: 我  爱  你
      ↓   ↓   ↓
    每个词都有 Q、K、V

Step 1: 计算注意力分数
    "我" 的 Q 与 "我""爱""你" 的 K 做点积
    → 得到 3 个分数（表示“我”和其他词的关系强度）

Step 2: Softmax 归一化
    → 分数变成概率（和为 1）

Step 3: 加权求和
    用这些概率对 3 个 V 做加权求和
    → 得到"我"的新特征（融合了上下文信息）

同样的过程对"爱"和"你"并行执行！
```



### 5.3 你的理解（完全正确）

> “Q 是要去查询和其他文字的权重关系；K 是每个字等待别人的 Q 来查；V 是每个字自己的内容，假如别人的 Q 来了和我的 K 计算得到了一个权重，然后就可以从我的 V 里面提取多少走。”

✅ **完全正确！**

## 六、Encoder 详解

### 6.1 输入处理

| 组件         | 作用                                               |
| :----------- | :------------------------------------------------- |
| **输入嵌入** | 把词 ID 转成向量                                   |
| **位置编码** | 注入位置信息（因为 Self-Attention 本身没有顺序感） |

### 6.2 Encoder 层内部结构

text

```
输入 x
    │
    ├── 多头自注意力（Multi-Head Self-Attention）
    │   └── Q、K、V 都来自 x（自己跟自己算）
    │
    ├── 残差连接：x + Attention(x)
    ├── LayerNorm
    │
    ├── 前馈网络（FFN）：两层全连接 + ReLU
    │
    ├── 残差连接：x + FFN(x)
    └── LayerNorm
```



### 6.3 关键点

| 关键点             | 说明                                 |
| :----------------- | :----------------------------------- |
| **Self-Attention** | 每个词都和所有词（包括自己）计算关系 |
| **残差连接**       | 防止梯度消失，让网络能更深           |
| **LayerNorm**      | 稳定训练                             |

## 七、Decoder 详解

### 7.1 Decoder 的两种注意力

Decoder 内部有两种不同的注意力机制：

text

```
Decoder 输入 y（已生成的上文）
    │
    ├── ① 带掩码的自注意力（Masked Self-Attention）
    │   └── Q、K、V 都来自自己，但只能看当前位置之前的词（不能偷看未来）
    │
    ├── 残差 + LayerNorm
    │
    ├── ② 交叉注意力（Cross-Attention）
    │   ├── Q：来自 Decoder（当前要生成的词）
    │   └── K、V：来自 Encoder 的输出（原句信息）
    │
    ├── 残差 + LayerNorm
    │
    ├── 前馈网络（FFN）
    └── 残差 + LayerNorm
```



### 7.2 两种注意力的对比

| 注意力类型                | Q 来自谁                   | K、V 来自谁                | 作用                       |
| :------------------------ | :------------------------- | :------------------------- | :------------------------- |
| **Masked Self-Attention** | Decoder 自己（已生成部分） | Decoder 自己（已生成部分） | 不能偷看未来词，保持自回归 |
| **Cross-Attention**       | Decoder 自己（当前词）     | Encoder 的输出             | 从原句中提取相关信息       |

### 7.3 为什么需要 Masked Self-Attention？

> 训练时，Decoder 知道整个目标序列（如“I love you”）。如果不加 Mask，生成“love”时能偷看到“you”，这就不对了。推理时没有这个问题（因为本来就没有未来词）。

> 💡 **Mask 的作用**：在 Self-Attention 计算时，把未来位置的值设为负无穷，Softmax 后变成 0。

## 八、Cross-Attention：Decoder 从 Encoder 取信息

> Encoder 提取完特征后，每个字都有一个融合了上下文的新特征向量。Decoder 中每个 Q（当前要生成的词）都要去和这些特征计算关系——关系近的多用用，关系远的少用用。

**这就是 Cross-Attention 做的事情**：

text

```
Encoder 输出:  [e₁, e₂, e₃]  ← 每个字的新特征
                    ↓
Decoder 的 Q（当前要预测的词）
    │
    ├── 和 e₁ 算权重 → 0.1
    ├── 和 e₂ 算权重 → 0.7  ← 重点关注“爱”
    └── 和 e₃ 算权重 → 0.2
                    ↓
              加权求和
                    ↓
          得到上下文向量
                    ↓
       结合当前状态预测下一个词
```



## 九、多头注意力（Multi-Head Attention）

### 9.1 为什么要多头？

> 一个注意力头只能关注一种关系模式。多头 = 多组 QKV 并行计算，每组学到不同的关系。

| 头     | 学到的关系           |
| :----- | :------------------- |
| Head 1 | 关注主语和动词的关系 |
| Head 2 | 关注修饰关系         |
| Head 3 | 关注远距离依赖       |
| ...    | ...                  |

> 💡 多组 QKV 并行 → 关注不同关系 → 最后拼接起来 → 更丰富的特征表达

## 十、位置编码

### 10.1 为什么要位置编码？

> Self-Attention 本身没有顺序感。“我爱你”和“你爱我”的 Attention 计算是一样的，但意思完全不同。

> 💡 位置编码把每个词的位置信息加入词向量，让模型知道“我”在第 1 位还是第 3 位。

### 10.2 你的理解

> “我爱你”和“你爱我”，“我”字融合的其他语义的信息是一样的，所以引入了位置编码，加入计算新的特征的过程，所以两个“我”就不一样了。

✅ **完全正确！** 位置编码让相同词在不同位置产生不同的特征。

## 十一、训练 vs 推理

### 11.1 训练阶段

| 组件    | 输入                            | 说明                                  |
| :------ | :------------------------------ | :------------------------------------ |
| Encoder | 完整输入序列                    | 一次性并行处理                        |
| Decoder | 真实目标序列（Teacher Forcing） | 用 Masked Self-Attention 防止偷看未来 |

> 💡 **Teacher Forcing**：训练时，不管 Decoder 上一步预测什么，都用**真实词**作为下一步输入，收敛更快。

### 11.2 推理阶段

text

```
输入: 完整原句
    ↓
Encoder: 一次性算出所有位置的特征
    ↓
Decoder: 自回归生成（串行）
    <SOS> → 预测 y₁
    y₁    → 预测 y₂
    y₂    → 预测 y₃
    ...   直到 <END>
```



### 11.3 你的理解（完全正确）

> “第一个输入是 <SOS>，然后去提取编码器里面的特征，然后融合成一个新东西去预测，然后输出的词当作下一个输入，也就是自回归。每次预测都会看 Encoder 的内容，解决了长距离依赖和语义问题。”

✅ **完全正确！**

## 十二、Encoder 训练时的梯度来源

> 你可能好奇：Encoder 没有直接预测任务，它的参数怎么更新？

**答案**：编码器的更新，完全依赖于解码器预测错误时传回来的梯度。

text

```
输入句子 → Encoder → 特征 → Decoder → 预测 → 算损失
                                         ↓
                              反向传播梯度传回来
                                ↓         ↓
                          Encoder 参数  Decoder 参数
                              都更新！    都更新！
```



## 十三、总结

### 13.1 一句话总结

> **Transformer = Encoder（提取特征）+ Decoder（自回归生成）+ 多头注意力 + 位置编码。**
