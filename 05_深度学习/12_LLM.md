# 12_LLM



# 大语言模型 LLM

> 你已经学完了 Transformer、BERT，现在我们来回答一个终极问题：ChatGPT 这些大模型到底是什么？怎么工作的？


## 一、课程引入

### 1.1 LLM ≠ 原始 Transformer

你学过的 Transformer 里的所有关键组件，LLM 全都有：

| 核心组件              | 作用                 | 是否被 LLM 继承    |
| --------------------- | -------------------- | ------------------ |
| 自注意力机制          | 让每个词看到整个序列 | ✅ 是（核心）       |
| 多头注意力            | 关注不同关系         | ✅ 是               |
| 残差连接              | 让网络能更深         | ✅ 是               |
| 层归一化（LayerNorm） | 稳定训练             | ✅ 是               |
| 前馈网络（FFN）       | 非线性变换           | ✅ 是               |
| 位置编码              | 注入顺序信息         | ✅ 是（形式可能变） |

> **区别在于**：原始 Transformer 是 Encoder + Decoder（为翻译设计），现代 LLM 几乎都只用 Decoder（自回归生成）。

### 1.2 LLM 选了 Decoder 这一条路

| 模型架构            | 代表模型               | 注意力方向     | 训练任务     | 擅长                         |
| ------------------- | ---------------------- | -------------- | ------------ | ---------------------------- |
| **Encoder only**    | BERT、RoBERTa          | 双向           | MLM + NSP    | 理解（分类、相似度、NER）    |
| **Decoder only**    | **GPT、LLaMA、Claude** | 单向（自回归） | 预测下一个词 | **生成（续写、对话、代码）** |
| **Encoder-Decoder** | 原始 Transformer、T5   | 双向 + 单向    | 翻译、摘要   | 序列到序列任务               |

> 💡 **核心结论**：现代 LLM（ChatGPT、Claude、LLaMA）全部属于 **Decoder only**。


## 二、LLM 是怎么工作的？

### 2.1 核心逻辑：和 RNN 生成文本时一模一样

> LLM 的核心计算方式和你之前学的 RNN 生成文本时一模一样：**用一个起始词，不断用自己的输出作为下一步输入，一直重复。**

**例子**：

输入："今天"
↓
模型输出："天气"
↓
输入："今天天气"
↓
模型输出："很好"
↓
输入："今天天气很好"
↓
模型输出："，"
↓
...（重复几千次）

text

```
> 💡 **区别**：RNN 每一步要重新计算整个隐藏状态，而 Transformer Decoder 每一步都能直接看到所有已生成的内容（通过自注意力）。

### 2.2 训练时：和 RNN 原理一样

> 你之前的理解完全正确：

> “训练的时候，一句话进去，通过词嵌入层转成 ID 转成向量，进去 Decoder，根据注意力机制去预测。训练的时候跟 RNN 的原理一样，输入都是真实值，然后更新的梯度只更新前向传播的网络层权重。”

| 参数类型 | 作用 | 是否可训练 |
|----------|------|------------|
| **Embedding 矩阵** | Token ID → 向量（查表） | ✅ 可训练 |
| **网络层权重** | Self-Attention、FFN、LayerNorm | ✅ 可训练（核心知识） |

> 💡 **关键**：embedding 层也是随机初始化的，不是用的训练好的词向量。所有参数都是从头开始训练的。


## 三、LLM 的三大组件详解

### 3.1 注意力层（QKV）

> 你之前的理解是对的：所有 token 用同一套投影规则，只是各自的输入向量 x 不同。
```



W_Q、W_K、W_V 的形状：[d_model, d_k]（例如 768×64）

对于句子"我 爱 你"：
Q_我 = x_我 · W_Q
Q_爱 = x_爱 · W_Q
Q_你 = x_你 · W_Q

公式里 W_Q 是同一个矩阵，所有 token 共用

text

```
> 💡 训练出来的是 **W_Q、W_K、W_V** 这些矩阵。Q 与 K 算的是“当前词（Q）如何看待其他词（K）”。

### 3.2 FFN（前馈网络）

> FFN = Feed-Forward Network，一个两层的全连接网络，夹在注意力层之间。

**作用**：

| 作用 | 说明 |
|------|------|
| **非线性变换** | 注意力机制本质是加权求和（线性），FFN 引入非线性，让模型能表达更复杂的函数 |
| **特征增强** | 把注意力提取出的信息“再加工”，让它对下一层更有用 |

> 💡 注意力机制是“收集信息”，FFN 是“思考信息”。你读完一段文字（注意力），然后在脑子里分析它（FFN）。

### 3.3 残差连接（Residual Connection）

> 把层的输入直接加到输出上：输出 = 层(x) + x

**作用**：

| 作用 | 说明 |
|------|------|
| **解决梯度消失** | 梯度可以从“捷径”直接传回去，不经过层内的复杂运算 |
| **让网络能堆得很深** | 没有残差，50 层几乎不可能训练；有了残差，1000 层也能训练 |

### 3.4 LayerNorm（层归一化）

> 把这一层输出的向量变成均值 0、方差 1（再学两个可调参数做缩放和平移）。
```



输出 = (x - mean) / std × γ + β

text

```
**作用**：

| 作用 | 说明 |
|------|------|
| **稳定训练** | 避免每层输出的数值范围过大或过小 |
| **加速收敛** | 让梯度更新更稳定，不需要反复调整学习率 |

### 3.5 三者 + 注意力 = Transformer 的一层
```



输入 x
│
├── 多头注意力（Multi-Head Attention）
│ ↓
├── 残差连接：x + Attention(x)
│ ↓
├── LayerNorm
│ ↓
├── FFN（两层全连接 + ReLU）
│ ↓
├── 残差连接：x + FFN(x)
│ ↓
└── LayerNorm
↓
输出到下一层

text

```
> 💡 你看到的所有“层堆叠”，本质上就是把这个块重复 N 遍（GPT-3 是 96 层）。


## 四、层数为什么能越堆越深？

| 模型 | 类型 | 层数（典型） | 说明 |
|------|------|--------------|------|
| RNN / LSTM | 循环 | 通常 1~4 层 | 层数多了梯度消失/爆炸严重 |
| 原始 Transformer | Encoder + Decoder | 各 6 层 | 论文标准配置 |
| BERT-base | Encoder only | 12 层 | 理解任务，深度翻倍 |
| BERT-large | Encoder only | 24 层 | 更大、更强 |
| GPT-3 / LLaMA | Decoder only | **96 层** | 生成任务，极深 |

### 为什么能堆这么深？

| 模型 | 深度限制原因 | 突破技术 |
|------|--------------|----------|
| RNN | 梯度消失（时间步乘矩阵） | ❌ 无法突破，天生缺陷 |
| Transformer | 梯度消失（深度方向） | ✅ 残差连接 + LayerNorm |
| BERT（12→24） | 深度训练稳定 | ✅ 预训练 + 更大数据 |
| LLM（96 层） | 工程极限（显存、时间） | ✅ 并行训练 + 分布式 + 混合精度 |


## 五、为什么 LLM 学习率要很小？

> 你的理解是对的：

> “LLM 的学习率小，不是因为它笨，而是因为它太敏感。一旦调多了，可能前向传播到深层的损失会极大。”

**解释**：
```



学习率大 → 参数更新幅度大
↓
深层网络微小变化被逐层放大
↓
输出剧烈震荡
↓
损失爆炸（变成 NaN）

text

```
> 💡 **经验法则**：模型越大，学习率要越小。GPT-3 的学习率通常在 1e-4 到 5e-5 之间。


## 六、你的理解（逐句确认）

### 关于训练参数

> “训练出来的参数，就只有前向传播的参数。”

✅ **对。** 这里的“前向传播的参数”= 网络层的权重（自注意力、FFN、LayerNorm 等）。

> “词向量那一块有额外的 embedding 层决定。”

✅ **对。** embedding 层也是参数，但它只是“查表”映射（Token ID → 向量）。

> “训练的时候，一句话进去，通过词嵌入层转成 ID，转成向量，进去 Decoder，根据注意力机制去预测。”

✅ **对。** 这是前向传播的第一步。

> “训练时跟 RNN 原理一样，输入都是真实值。”

✅ **对。** Teacher Forcing：每一步输入都是真实的上一个词，不是模型自己猜的。

> “更新的梯度只更新前向传播的网络层权重。”

✅ **对。** 梯度会更新所有可训练参数：embedding 层 + 网络层。但“核心知识”在网络层里。

### 关于学习率

> “学习率大 → 参数更新幅度大 → 深层网络微小变化被逐层放大 → 输出剧烈震荡 → 损失爆炸（变成 NaN）。”

✅ **完全正确！** 这就是为什么大模型需要小学习率。


## 七、面试回答模板（总分总）

> **总（10秒）**：LLM 的本质就是巨大的 Transformer Decoder + 海量数据 + 大力出奇迹。

> **分（60秒）**：
> 1. **架构**：现代 LLM（GPT、LLaMA、Claude）全部采用 Decoder only 架构，用自回归方式生成文本。
> 2. **工作方式**：和 RNN 生成文本一样——用起始词启动，不断用自己的输出作为下一步输入，自回归生成。
> 3. **组件**：自注意力（让每个词看到整个序列）+ FFN（非线性变换）+ 残差连接（让网络能深）+ LayerNorm（稳定训练）。
> 4. **训练**：用 Teacher Forcing（真实词作为输入），用海量文本做下一个词预测。模型越大，学习率要越小。

> **总（10秒）**：LLM = 超深 Transformer Decoder + 超大数据 + 超强算力，通过预测下一个词学会生成能力。


## 八、总结

### 一句话总结

> **LLM = 巨大的 Transformer Decoder + 海量数据 + 大力出奇迹。**
```
