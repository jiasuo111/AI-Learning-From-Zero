# 模型压缩

> 大模型效果虽好，但体积太大、推理太慢。模型压缩就是让大模型“瘦身”的技术，让你能在手机、边缘设备上跑起来。

## 一、课程引入

### 1.1 为什么要压缩模型？

你学过的模型越来越大：

| 模型       | 参数量  | 存储大小 |
| ---------- | ------- | -------- |
| BERT-base  | 1.1 亿  | ~400 MB  |
| BERT-large | 3.4 亿  | ~1.2 GB  |
| GPT-3      | 1750 亿 | ~700 GB  |
| LLaMA-70B  | 700 亿  | ~280 GB  |

> 问题：这些模型太大了，无法在手机、嵌入式设备上运行。

**解决方案：模型压缩**

### 1.2 什么是模型压缩？

**一句话定义**：在模型性能影响不大的前提下，通过减少模型参数量和精度来减少存储空间、提升推理效率。

> 核心目标：减体积 + 加速度 + 保精度


## 二、四大压缩技术

### 2.1 量化（Quantization）

> 减少模型清晰度——把每一个参数的精度降低。

**具体做法**：

| 精度类型 | 存储  | 说明                   |
| -------- | ----- | ---------------------- |
| FP32     | 32 位 | 原始精度（训练时用）   |
| FP16     | 16 位 | 半精度                 |
| INT8     | 8 位  | 整数精度（推理时常用） |

**为什么量化有效？**

| 优势     | 说明                               |
| -------- | ---------------------------------- |
| 存储减半 | FP32 → INT8，参数量变为 **1/4**    |
| 计算加速 | 整数运算比浮点运算快得多           |
| 硬件友好 | 手机、嵌入式设备对 INT8 有原生支持 |

> 💡 **量化粒度的比喻**：把一张高清照片（FP32）压缩成低分辨率图片（INT8）。细节丢失了，但轮廓还在。模型推理时只看“轮廓”就够了。

### 2.2 蒸馏（Knowledge Distillation）

> 用一个大而强的模型（教师）去指导一个小而轻的模型（学生）训练，让学生模仿教师的输出分布。

┌─────────────────┐ ┌─────────────────┐
│ 教师模型（大） │ ──蒸馏指导──→ │ 学生模型（小） │
│ BERT-large │ │ BiLSTM/小BERT │
│ 效果好、太慢 │ │ 效果接近、快 │
└─────────────────┘ └─────────────────┘

text

```
**损失函数**：

> 总损失 = α × 硬标签损失 + (1-α) × 蒸馏损失

| 损失类型 | 说明 |
|----------|------|
| **硬标签损失** | 学生预测 vs 真实标签（CrossEntropy） |
| **蒸馏损失** | 学生预测 vs 教师预测（KL散度） |

**蒸馏的关键技术：温度系数 T**
```



标准 Softmax: P = exp(z/T) / Σexp(z/T)

T=1：标准分布，负类概率接近 0
T>1：分布变平滑，负类概率被放大 → 传递更多类间相似性信息

text

```
> 💡 训练学生时用 T>1，推理时 T=1

### 2.3 剪枝（Pruning）

> 删除模型中不重要的参数（权重或神经元），减少参数量，同时尽量保持精度。

**两种粒度**：

| 类型 | 操作 | 效果 |
|------|------|------|
| **非结构化剪枝** | 删除单个权重（置零），稀疏矩阵 | 压缩率高，但需要特殊硬件支持 |
| **结构化剪枝** | 删除整个神经元或卷积通道 | 硬件友好，可直接加速，精度损失可能更大 |

**两种操作方式**：

| 方式 | 说明 |
|------|------|
| **逻辑剪枝** | 将权重置为 0，但结构仍在，便于恢复 |
| **物理剪枝** | 从模型中永久删除参数，最终部署时减小体积 |

**剪枝流程**：

> 训练 → 评估参数重要性 → 剪掉不重要的 → 微调 →（可选重复）

**重要性评估方法**：

| 方法 | 原理 |
|------|------|
| 基于绝对值 | \|w\| 越小，越不重要 |
| 基于梯度 | 梯度 × 权重 小，不重要 |
| 基于 Hessian | 二阶信息，计算量大 |

### 2.4 低秩分解

> 将一个大权重矩阵分解成两个小矩阵的乘积，从而减少参数量。

**原理**：`W (m×n) ≈ U (m×r) × V (r×n)`，其中 r << min(m, n)

**参数量对比**：

| 方案 | 参数量 |
|------|--------|
| 原始矩阵 | m × n |
| 低秩分解后 | r × (m + n) |

> 💡 参数量从 m×n 降到 r×(m+n)，大幅减少

**各技术定位**：

| 技术 | 本质 | 主要目的 |
|------|------|----------|
| 量化 | 减少每个参数的位数 | 减少存储、加速计算 |
| 蒸馏 | 大模型教小模型 | 减小模型体积、保持效果 |
| 剪枝 | 删掉不重要的参数 | 减少参数量、加速推理 |
| 低秩分解 | 用两个小矩阵替换大矩阵 | 减少参数量 |


## 三、蒸馏实战：BiLSTM 蒸馏 BERT

### 3.1 为什么用 BiLSTM 蒸馏 BERT？

| 对比 | BERT | BiLSTM |
|------|------|--------|
| 参数量 | 1.1 亿 | 几百万 |
| 推理速度 | 慢 | 快 10-100 倍 |
| 部署难度 | 高（需要 GPU） | 低（CPU 可运行） |

### 3.2 核心处理：输入格式对齐

> 蒸馏时最大的坑：**教师和学生的输入格式不同**。

| 模型 | 输入 | 特殊标记 |
|------|------|----------|
| BERT（教师） | Token IDs + Attention Mask | [CLS]、[SEP]、[PAD] |
| BiLSTM（学生） | 词向量 | 无 |

**解决方案**：
```



1. BERT 输入有 [CLS]、[SEP]、[PAD] 这些特殊 token
2. 蒸馏时要把这些特殊 token 对应的向量置 0
3. 确保学生只学习“真正有意义的词”的特征

text

```
### 3.3 蒸馏代码结构

​```python
# 教师模型（已训练好的 BERT）
teacher = BertForSequenceClassification.from_pretrained("bert-base")

# 学生模型（BiLSTM 分类器）
class StudentModel(nn.Module):
    def __init__(self, vocab_size, embed_dim, hidden_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, num_classes)
        self.dropout = nn.Dropout(0.3)
    
    def forward(self, input_ids, attention_mask=None):
        # 处理 padding：将 [PAD] 位置向量置 0
        x = self.embedding(input_ids)
        if attention_mask is not None:
            x = x * attention_mask.unsqueeze(-1)  # 将 padding 位置的向量置 0
        x, _ = self.lstm(x)
        # 取最后一个有效 token 的输出
        x = self.dropout(x[:, -1, :])
        return self.fc(x)

# 损失函数
def distillation_loss(student_logits, teacher_logits, labels, temperature, alpha):
    # 软标签损失（蒸馏损失）：KL 散度
    soft_loss = kl_div(
        F.log_softmax(student_logits / temperature, dim=-1),
        F.softmax(teacher_logits / temperature, dim=-1),
        reduction='batchmean'
    )
    # 硬标签损失：交叉熵
    hard_loss = F.cross_entropy(student_logits, labels)
    # 总损失
    return alpha * hard_loss + (1 - alpha) * soft_loss * (temperature ** 2)

# 训练循环
for batch in dataloader:
    with torch.no_grad():
        teacher_logits = teacher(input_ids, attention_mask)
    student_logits = student(input_ids, attention_mask)
    loss = distillation_loss(student_logits, teacher_logits, labels, temperature=4, alpha=0.3)
    loss.backward()
    optimizer.step()
```



## 四、压缩策略组合

> 四种压缩技术可以组合使用，效果更好。

### 4.1 推荐策略

text

```
训练好的大模型
    │
    ├── 蒸馏 → 得到小模型（体积减小）
    │       ↓
    ├── 剪枝 → 删除不重要参数（体积再减）
    │       ↓
    └── 量化 → FP32 → INT8（体积再减 1/4）
            ↓
        最终部署模型
```



### 4.2 组合效果

| 步骤                  | 模型大小 | 推理速度 |
| :-------------------- | :------- | :------- |
| 原始模型（BERT-base） | 400 MB   | 1×       |
| 蒸馏后（BiLSTM）      | 20 MB    | 10×      |
| + 剪枝                | 12 MB    | 15×      |
| + 量化（INT8）        | 3 MB     | 30×      |

## 五、优缺点对比

### 5.1 各技术对比

| 技术         | 优点               | 缺点                   | 适用场景       |
| :----------- | :----------------- | :--------------------- | :------------- |
| **量化**     | 简单、通用、效果好 | 精度有损失             | 所有模型都能用 |
| **蒸馏**     | 可大幅减小模型     | 需要训练、需要教师模型 | 追求极限压缩   |
| **剪枝**     | 可直接加速         | 精度损失可能大         | 追求推理速度   |
| **低秩分解** | 理论优雅           | 实现复杂               | 特定层优化     |

### 5.2 选择建议

| 场景               | 推荐方案             |
| :----------------- | :------------------- |
| 想在手机跑模型     | 量化 + 剪枝          |
| 想最大程度减小模型 | 蒸馏 + 量化          |
| 追求推理速度       | 剪枝 + 量化          |
| 精度要求高         | 蒸馏（学生接近教师） |

## 六、面试回答模板（总分总）

> **总（10秒）**：模型压缩是在保持模型性能的前提下，通过量化、蒸馏、剪枝、低秩分解等方法减小模型体积、加速推理，是模型落地的重要技术。

> **分（60秒）**：
>
> 1. **量化**：降低参数精度（FP32→INT8），减少存储和计算量，所有模型都能用。
> 2. **蒸馏**：大模型（教师）教小模型（学生），让学生模仿教师的软标签输出，损失函数包括硬标签交叉熵和软标签 KL 散度。
> 3. **剪枝**：删除不重要的权重或神经元，分非结构化（权重级）和结构化（神经元/通道级）两种。
> 4. **低秩分解**：用两个小矩阵近似大矩阵，减少参数量。

> **总（10秒）**：四种技术各有所长，实践中常组合使用（如先蒸馏再量化，或先剪枝再量化）。

## 七、总结

### 一句话总结

> **模型压缩 = 量化 + 蒸馏 + 剪枝 + 低秩分解，让大模型能在小设备上跑起来。**
