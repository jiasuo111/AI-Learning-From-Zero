# 🚀 从零开始的AI学习之路

> 一个普通AI专业大四学生的自学笔记 —— 踩过的坑，我都帮你踩过了。

你们好呀，我是**小迦索**，迦南的迦，亚索的索。

一个正在为毕业和找工作冲刺的AI专业大四学生。


## 📖 这篇文章写给谁？

如果你：

- 想学AI大模型，但不知道怎么下手
- 收藏了一堆教程，看了两集就吃灰了
- 被各种专业术语劝退："神经网络"、"Transformer"、"RAG"...
- 配个环境配到怀疑人生，还没开始就结束了
- 学了各种知识点，但**串不到一起**，不知道它们之间什么关系

那你和我一样。这些都是我真实经历过的。


## 🧠 为什么我想做这件事？

说实话，我不是大佬，没发过顶会，没在大厂实习过。

大学前三年，我打游戏多于写代码，真正开始系统学AI，也就是这一年的事。

刚开始的时候真的很痛苦：

**环境配置是第一个坎。**
> 新手连软件都不会装。Python 版本、CUDA 版本、PyTorch 版本——稍微一个不对，教程就跑不起来。更别提磁盘管理、环境变量、C盘爆满这些问题了。我有一半的时间不是在学AI，是在「修复我的电脑」。

**第二个坎是「知识点是散的」。**
> 学了 Python，学了 MySQL，学了点 Linux，学了网络编程——但这些东西是怎么组成一个「系统」的？容器、网络协议、端口、IP、架构……这些到底怎么串起来？说实话，我现在也不敢说自己完全搞懂了。这些需要**日积月累**，不是看几节课就能解决的。

**第三个坎是「靠谱的学习资源太难找了」。**
> 网上资料一大把，但能**从0开始、每一步都讲清楚**的少之又少。各种付费课程更是踩坑重灾区，花了大几百，学出来的东西根本用不上。

这些困难，我现在还在面对。

所以我想做一件事——**把我正在学的东西，用最人话的方式整理出来**。

不是为了当老师，而是为了：
- 让自己学得更扎实（教是最好的学）
- 给和我一样正在挣扎的AI学习者一个参考
- 给自己的毕业求职攒一份拿得出手的作品
